ត្រឡប់ក្រោយ
គណិតវិទ្យា • ជំពូកទី ១

មេរៀនទី ១ ៖ ចំនួនកុំផ្លិច

ទម្រង់ពីជគណិត ទម្រង់ត្រីកោណមាត្រ ម៉ូឌុល អាគុយម៉ង់ និងស្វ័យគុណទី n

១. តើចំនួនកុំផ្លិចជាអ្វី?
ចំនួនកុំផ្លិច គឺជាចំនួនដែលមានទម្រង់ $z = a + bi$ ដែល៖
  • $a$ ជាផ្នែកពិត (Real Part) សរសេរ $\text{Re}(z) = a$
  • $b$ ជាផ្នែកនិម្មិត (Imaginary Part) សរសេរ $\text{Im}(z) = b$
  • $i$ ជាអង្គភាពនិម្មិត (Imaginary Unit) ដែលមានលក្ខណៈ $i^2 = -1$
$$z = a + bi \quad \text{ដែល} \quad a, b \in \mathbb{R} \quad \text{និង} \quad i^2 = -1$$
២. លក្ខណៈនៃអង្គភាពនិម្មិត $i$ និងស្វ័យគុណ $i^n$
អង្គភាពនិម្មិត $i$ គឺជាចំនួនដែល $i^2 = -1$ ឬ $i = \sqrt{-1}$។
ស្វ័យគុណរបស់ $i$ មានលក្ខណៈជាវដ្ត (cycle length = 4) ៖
$$i^0 = 1, \quad i^1 = i, \quad i^2 = -1, \quad i^3 = -i, \quad i^4 = 1, \quad \dots$$
វិធីគណនា $i^n$ ៖ យក $n$ ចែកនឹង $4$ រួចពិនិត្យសំណល់ $r$ ៖
  • សំណល់ $r = 0 \Rightarrow i^n = 1$
  • សំណល់ $r = 1 \Rightarrow i^n = i$
  • សំណល់ $r = 2 \Rightarrow i^n = -1$
  • សំណល់ $r = 3 \Rightarrow i^n = -i$
៣. ភាពស្មើគ្នានៃចំនួនកុំផ្លិចពីរ
ចំនួនកុំផ្លិចពីរ $z_1 = a_1 + b_1 i$ និង $z_2 = a_2 + b_2 i$ ស្មើគ្នា លុះត្រាតែផ្នែកពិតស្មើគ្នា និង ផ្នែកនិម្មិតស្មើគ្នា ៖
$$z_1 = z_2 \iff a_1 = a_2 \quad \text{និង} \quad b_1 = b_2$$
៤. ប្រមាណវិធីលើចំនួនកុំផ្លិច
ចំពោះ $z_1 = a + bi$ និង $z_2 = c + di$ ៖
ប្រមាណវិធី រូបមន្ត
បូក (Addition) $z_1 + z_2 = (a+c) + (b+d)i$
ដក (Subtraction) $z_1 - z_2 = (a-c) + (b-d)i$
គុណ (Multiplication) $z_1 \cdot z_2 = (ac - bd) + (ad + bc)i$
ចែក (Division) $\displaystyle \frac{z_1}{z_2} = \frac{(ac+bd) + (bc-ad)i}{c^2 + d^2}$
ឧទាហរណ៍ ៖ គណនា $(3 + 2i)(1 - 4i)$
$$= 3(1) + 3(-4i) + 2i(1) + 2i(-4i)$$ $$= 3 - 12i + 2i - 8i^2$$ $$= 3 - 10i - 8(-1)$$ $$= 3 - 10i + 8 = 11 - 10i$$
៥. ចំនួនកុំផ្លិចឆ្លាស់ (Complex Conjugate)
បើ $z = a + bi$ នោះចំនួនកុំផ្លិចឆ្លាស់របស់វា សរសេរ $\bar{z}$ គឺ ៖
$$\bar{z} = a - bi$$
លក្ខណៈសម្បត្តិសំខាន់ៗ ៖
  • $z + \bar{z} = 2a = 2\,\text{Re}(z)$
  • $z - \bar{z} = 2bi = 2i\,\text{Im}(z)$
  • $z \cdot \bar{z} = a^2 + b^2 = |z|^2$
  • $\overline{z_1 + z_2} = \bar{z}_1 + \bar{z}_2$
  • $\overline{z_1 \cdot z_2} = \bar{z}_1 \cdot \bar{z}_2$
៦. ម៉ូឌុលនៃចំនួនកុំផ្លិច (Modulus)
ម៉ូឌុល (Modulus) នៃ $z = a + bi$ សរសេរ $|z|$ គឺជាចម្ងាយពីគល់តម្រុយ $O$ ដល់ចំណុចរូបភាព $M(a, b)$ ៖
$$|z| = \sqrt{a^2 + b^2}$$
ឧទាហរណ៍ ៖
ចំពោះ $z = 3 + 4i$ នោះ $|z| = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$
លក្ខណៈសម្បត្តិ ៖
  • $|z| \geq 0$ និង $|z| = 0 \iff z = 0$
  • $|z_1 \cdot z_2| = |z_1| \cdot |z_2|$
  • $\displaystyle \left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}$ ចំពោះ $z_2 \neq 0$
  • $|z_1 + z_2| \leq |z_1| + |z_2|$ (វិសមភាពត្រីកោណ)
៧. តំណាងភូមិសាស្ត្រក្នុងប្លង់កុំផ្លិច (Argand Diagram)
ចំនួនកុំផ្លិច $z = a + bi$ ត្រូវតំណាងដោយចំណុច $M(a, b)$ ក្នុងប្លង់កុំផ្លិច ៖
  • អ័ក្សផ្ដេក ($Ox$) គឺជាអ័ក្សពិត (Real Axis)
  • អ័ក្សឈរ ($Oy$) គឺជាអ័ក្សនិម្មិត (Imaginary Axis)
  • ប្រវែង $\overline{OM} = r = |z|$ ជាម៉ូឌុល
  • មុំ $\theta = (\overrightarrow{Ox}, \overrightarrow{OM})$ ជាអាគុយម៉ង់ $\arg(z)$

តំណាងចំណុច $M(a, b)$ នៃចំនួនកុំផ្លិច $z = a + bi$ ក្នុងប្លង់ Argand

៨. ទម្រង់ត្រីកោណមាត្រ (Trigonometric Form)
គ្រប់ចំនួនកុំផ្លិច $z \neq 0$ អាចសរសេរជាទម្រង់ត្រីកោណមាត្រ ៖
$$z = r(\cos\theta + i\sin\theta)$$
ដែល ៖
  • $r = |z| = \sqrt{a^2 + b^2}$ ជាម៉ូឌុល
  • $\theta = \arg(z)$ ជាអាគុយម៉ង់ (Argument)
  • $a = r\cos\theta$ និង $b = r\sin\theta$
រូបមន្តរកមុំ $\theta$ ៖ $$\cos\theta = \frac{a}{r}, \quad \sin\theta = \frac{b}{r}$$
៩. គុណ និងចែកទម្រង់ត្រីកោណមាត្រ
បើ $z_1 = r_1(\cos\theta_1 + i\sin\theta_1)$ និង $z_2 = r_2(\cos\theta_2 + i\sin\theta_2)$ នោះ ៖
គុណ ៖ $$z_1 \cdot z_2 = r_1 r_2 \big[\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)\big]$$
ចែក ៖ $$\frac{z_1}{z_2} = \frac{r_1}{r_2} \big[\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)\big]$$
វិធានចងចាំ ៖ គុណម៉ូឌុល បូកមុំ; ចែកម៉ូឌុល ដកមុំ។
១០. រូបមន្ត De Moivre (De Moivre's Theorem)
រូបមន្ត De Moivre សម្រាប់គណនាស្វ័យគុណទី $n$ នៃចំនួនកុំផ្លិច ៖
$$\big[\cos\theta + i\sin\theta\big]^n = \cos(n\theta) + i\sin(n\theta)$$
ដូចនេះចំពោះ $z = r(\cos\theta + i\sin\theta)$ ៖
$$z^n = r^n \big[\cos(n\theta) + i\sin(n\theta)\big]$$
ឧទាហរណ៍ ៖ គណនា $(1 + i)^8$
១. សរសេរ $1 + i$ ជាទម្រង់ត្រីកោណមាត្រ ៖ $r = \sqrt{2}, \quad \theta = \frac{\pi}{4}$
$$1 + i = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)$$ ២. ប្រើរូបមន្ត De Moivre ៖ $$(1+i)^8 = (\sqrt{2})^8 \left(\cos\frac{8\pi}{4} + i\sin\frac{8\pi}{4}\right) = 16(\cos 2\pi + i\sin 2\pi) = 16(1 + 0) = 16$$
១១. ទម្រង់អិចស្ប៉ូណង់ស្យែល (Exponential Form)
តាមរូបមន្ត Euler ($e^{i\theta} = \cos\theta + i\sin\theta$) ៖
$$z = r \cdot e^{i\theta}$$
ប្រមាណវិធី ៖
  • $z_1 \cdot z_2 = r_1 r_2 \cdot e^{i(\theta_1 + \theta_2)}$
  • $\displaystyle \frac{z_1}{z_2} = \frac{r_1}{r_2} \cdot e^{i(\theta_1 - \theta_2)}$
  • $z^n = r^n \cdot e^{in\theta}$
១២. ឫសទី $n$ នៃចំនួនកុំផ្លិច (n-th Roots)
ចំនួនកុំផ្លិច $z = r(\cos\theta + i\sin\theta) \neq 0$ មានឫសទី $n$ ចំនួន $n$ ឫសផ្សេងៗគ្នា ៖
$$w_k = \sqrt[n]{r} \left(\cos\frac{\theta + 2k\pi}{n} + i\sin\frac{\theta + 2k\pi}{n}\right)$$ $$\text{ចំពោះ } k = 0, 1, 2, \ldots, n-1$$
១៣. ការដោះស្រាយសមីការដឺក្រេទី២ $az^2 + bz + c = 0$ ក្នុងសំណុំ $\mathbb{C}$
គណនាដេស្គ្រីមីណង់ $\Delta = b^2 - 4ac$ ៖
  • បើ $\Delta > 0$ ៖ មានឫសពិតពីរ $z_{1,2} = \frac{-b \pm \sqrt{\Delta}}{2a}$
  • បើ $\Delta = 0$ ៖ មានឫសឌុប $z_1 = z_2 = -\frac{b}{2a}$
  • បើ $\Delta < 0$ ៖ មានឫសកុំផ្លិចឆ្លាស់ពីរ $z_{1,2} = \frac{-b \pm i\sqrt{|\Delta|}}{2a}$
ដោះស្រាយសមីការ $z^2 + 2z + 5 = 0$ ៖ $$\Delta = b^2 - 4ac = 2^2 - 4(1)(5) = 4 - 20 = -16 < 0$$ $$\sqrt{\Delta} = \sqrt{-16} = 4i$$ $$z = \frac{-2 \pm 4i}{2(1)} = -1 \pm 2i$$
ដូចនេះ ឫសនៃសមីការគឺ $z_1 = -1 + 2i$ និង $z_2 = -1 - 2i$
១៤. សង្ខេបរូបមន្តសំខាន់ៗនៃមេរៀន
ឈ្មោះ / ទម្រង់ រូបមន្ត
ទម្រង់ពីជគណិត $z = a + bi \quad (i^2 = -1)$
