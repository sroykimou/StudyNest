វិញ្ញាសា គណិតវិទ្យា (វិទ្យាសាស្ត្រពិត) ១០

សម្រាប់ការត្រៀមប្រឡងសញ្ញាបត្រមធ្យមសិក្សាទុតិយភូមិ

រយៈពេល៖ ១៥០ នាទី ពិន្ទុសរុប៖ ១២៥ ពិន្ទុ

លំហាត់ I

គណនាលីមីតខាងក្រោម៖

ក. $\lim_{x \to -1} \frac{-x^2 + 2x + 3}{x^5 + 1}$

ខ. $\lim_{x \to 0} \frac{\ln(\cos ax)}{\ln(\cos bx)}$

គ. $\lim_{x \to \infty} \left(\frac{x-1}{x+3}\right)^{x+1}$

ឃ. $\lim_{x \to 0^+} x^x$

ដំណោះស្រាយ

ក. $\lim_{x \to -1} \frac{-x^2 + 2x + 3}{x^5 + 1} = \frac{4}{5}$

ខ. $\lim_{x \to 0} \frac{\ln(\cos ax)}{\ln(\cos bx)} = \left(\frac{a}{b}\right)^2$

គ. $\lim_{x \to \infty} \left(\frac{x-1}{x+3}\right)^{x+1} = \frac{1}{e^4}$

ឃ. $\lim_{x \to 0^+} x^x = 1$

លំហាត់ II

គេឱ្យចំនួនកុំផ្លិច $z_1 = 1 + i$ និង $z_2 = (\sqrt{3}+1) + i(\sqrt{3}-1)$។

ក. សរសេរ $z = z_1 \times z_2$ ជាទម្រង់ពីជគណិត និងត្រីកោណមាត្រ។

ខ. សរសេរ $z_1, z$ ជាទម្រង់ត្រីកោណមាត្រ រួចកំណត់ទម្រង់ត្រីកោណមាត្រនៃ $z_2$។

គ. កំណត់ចំនួន $n$ ដើម្បីឱ្យ $z^n$ ជាចំនួននិមិត្តសុទ្ធ។

ដំណោះស្រាយ

ក. $z = 2 + 2i\sqrt{3}$ និង $z = 4(\cos \frac{\pi}{3} + i\sin \frac{\pi}{3})$

ខ. $z_1 = \sqrt{2}(\cos \frac{\pi}{4} + i\sin \frac{\pi}{4})$ និង $z_2 = 2\sqrt{2}(\cos \frac{\pi}{12} + i\sin \frac{\pi}{12})$

គ. $n = \frac{3}{2}(2k - 1)$ ដែល $k \in \mathbb{N}$

លំហាត់ III

ក្នុងថង់មួយមានប៊ូលក្រហម $5$ ខ្មៅ $7$ និងខៀវ $8$ គ្រាប់។ គេចាប់យកប៊ូលពីរគ្រាប់ម្តងមួយៗ ដោយមិនដាក់ចូលវិញ។ រកប្រូបាបនៃព្រឹត្តិការណ៍៖

A: ចាប់បានប៊ូលក្រហមនៅលើកទី១ និងខៀវនៅលើកទី២។

B: ចាប់បានប៊ូលពណ៌ដូចគ្នា។

C: ចាប់បានប៊ូលពណ៌ខុសគ្នា។

ដំណោះស្រាយ

A. $P(A) = \frac{2}{19}$

B. $P(B) = \frac{59}{190}$

C. $P(C) = \frac{131}{190}$

លំហាត់ IV

១. គណនាអាំងតេក្រាល $I = \int_{2}^{4} \frac{x^2 dx}{x^2 - 2x + 2}$ និង $J = \int_{\frac{\pi}{6}}^{\frac{\pi}{3}} (\tan x - \cot x)^2 dx$។

២. គេឱ្យសមីការឌីផេរ៉ង់ស្យែល $(E): y'' - 2y' + y = \frac{4x - 4}{e^x}$ និង $(F): y'' - 2y' + y = 0$។

ក. កំណត់ចំនួនពិត $\alpha, \beta$ ដើម្បីឱ្យ $g(x) = \frac{\alpha x + \beta}{e^x}$ ជាចម្លើយមួយនៃ $(E)$។

ខ. បង្ហាញថាបើ $f(x) = g(x) + h(x)$ ជាចម្លើយនៃ $(E)$ នោះ $h(x)$ ជាចម្លើយនៃ $(F)$។

គ. ដោះស្រាយសមីការ $(F)$ រួចទាញរកចម្លើយទូទៅនៃ $(E)$។

ដំណោះស្រាយ

១. $I = 2 + \ln 5$ និង $J = \frac{4\sqrt{3} - 2\pi}{3}$

២.

ក. $\alpha = 1$ និង $\beta = 0$

ខ. តាមសម្រាយបញ្ជាក់

គ. ចម្លើយទូទៅ $(E)$ គឺ $y = \frac{x}{e^x} + (Ax + B)e^x$ ដែល $A, B \in \mathbb{R}$

លំហាត់ V

ក្នុងតម្រុយអរតូណរម៉ាល់មានទិសដៅវិជ្ជមាន $(O, \vec{i}, \vec{j}, \vec{k})$ គេឱ្យប្លង់ $(P): x + 2y + 2z - 4 = 0$ និងចំណុច $P(1, 2, 4)$។

ក. កំណត់សមីការប៉ារ៉ាម៉ែត្របន្ទាត់ $(L)$ ដែលកាត់តាមចំណុច $P$ ហើយកែងនឹងប្លង់ $(P)$ ត្រង់ $Q$។ រកកូអរដោនេចំណុច $Q$។

ខ. កំណត់សមីការស្វ៊ែរ $(S)$ មានផ្ចិត $P$ ហើយប៉ះទៅនឹងប្លង់ $(P)$។

គ. ប្លង់ $(P)$ កាត់អ័ក្ស $(ox), (oy)$ និង $(oz)$ រៀងគ្នាត្រង់ $A, B$ និង $C$។ រកកូអរដោនេចំណុច $A, B, C$។

ឃ. គណនា $\vec{n} = \vec{AB} \times \vec{AC}$ រួចទាញរក $S_{ABC}$ និង $V_{PABC}$។

ដំណោះស្រាយ

ក. $(L): x = t + 1, y = 2t + 2, z = 2t + 4$ និង $Q(0, 0, 2)$

ខ. $(S): (x - 1)^2 + (y - 2)^2 + (z - 4)^2 = 9$

គ. $A(4, 0, 0)$, $B(0, 2, 0)$ និង $C(0, 0, 2)$

ឃ. $S_{ABC} = 6$ ឯកតាផ្ទៃ, $V_{PABC} = 6$ ឯកតាមាឌ

លំហាត់ VI

អ៊ីពែបូលមួយមានកំពូល $V_1(3, 0)$ និង $V_2(-3, 0)$ ហើយកាត់តាមចំណុច $P(5, 2)$។ សរសេរសមីការស្តង់ដា រួចសង់អ៊ីពែបូល។

ដំណោះស្រាយ

សមីការស្តង់ដា៖ $\frac{x^2}{3^2} - \frac{y^2}{1.5^2} = 1$

លំហាត់ VII

១. គណនាដេរីវេទីមួយ និងទាញរកសញ្ញានៃអនុគមន៍ $g(x) = 2\ln x - x^2 - 2$ ដែល $x > 0$ ដោយមិនបាច់រកលីមីតចុងដែនកំណត់។

២. គេឱ្យអនុគមន៍ $f(x) = 1 - x - \frac{2\ln x}{x} ; x > 0$។

ក. គណនា $f'(x)$ រួចទាញរកសញ្ញានៃ $f'(x)$។

ខ. គណនាលីមីតចុងដែនកំណត់ រួចទាញរកអាស៊ីមតូតឈរនៃក្រាប $(C)$ តាងអនុគមន៍ $f$។

គ. បង្ហាញថាបន្ទាត់ $(L): y = 1 - x$ ជាអាស៊ីមតូតទ្រេតនៃ $(C)$។

ឃ. រកសមីការបន្ទាត់ $(T)$ ប៉ះក្រាប $(C)$ ហើយស្របនឹងបន្ទាត់ $(L)$។

ង. គណនា $f(1)$ រួចសង់តារាងអថេរភាព $f$។

ច. សង់ក្រាប $(C); (L)$ និង $(T)$ ក្នុងតម្រុយតែមួយ។ (គេឱ្យ $e \approx 2.7 ; \frac{2}{e} \approx 0.7$)

ឆ. គណនាផ្ទៃក្រឡានៃប្លង់ខណ្ឌដោយ $(C)$ និង $(L)$ នៅចន្លោះបន្ទាត់ $x = 1, x = e$។

ដំណោះស្រាយ

១. $g'(x) = \frac{2(1 - x^2)}{x}$ និង $g(x) < 0$ ចំពោះគ្រប់ $x > 0$

២.

ក. $f'(x) = \frac{2\ln x - x^2 - 2}{x^2} = \frac{g(x)}{x^2}$ នាំឱ្យ $f'(x) < 0$ ជានិច្ច

ខ. $x = 0$ ជាអាស៊ីមតូតឈរ

គ. $(L): y = 1 - x$ ជាអាស៊ីមតូតទ្រេត

ឃ. $(T): y = -x + 1 - \frac{2}{e}$

ង. $f(1) = 0$

ឆ. $S = 1$ ឯកតាផ្ទៃ
