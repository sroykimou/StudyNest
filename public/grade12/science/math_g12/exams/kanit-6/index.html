វិញ្ញាសា គណិតវិទ្យា (វិទ្យាសាស្ត្រពិត) ០៦

សម្រាប់ការត្រៀមប្រឡងសញ្ញាបត្រមធ្យមសិក្សាទុតិយភូមិ

រយៈពេល៖ ១៥០ នាទី ពិន្ទុសរុប៖ ១២៥ ពិន្ទុ

លំហាត់ I

គេឱ្យសមីការ $(E): z^2 + iaz + a + ib = 0$ ដែល $a, b \in \mathbb{R}$ ។

ក. កំណត់ $a, b$ ដើម្បីឱ្យ $z_1 = -1 + i\sqrt{3}$ ជាឫសមួយនៃសមីការ $(E)$ រួចទាញរកឫសមួយទៀត។

ខ. សរសេរ $z_1 , z_2$ និង $\frac{z_1}{z_2}$ ជាទម្រង់ត្រីកោណមាត្រ។

គ. ទាញរកតម្លៃប្រាកដនៃ $\cos\frac{5\pi}{12}$ និង $\sin\frac{5\pi}{12}$ ។

ដំណោះស្រាយ

ក. កំណត់ $a, b$ និងទាញរកឫសមួយទៀត៖

ដោយ $z_1 = -1 + i\sqrt{3}$ ជាឫសនៃ $(E)$ នាំឱ្យ៖

$(-1 + i\sqrt{3})^2 + ia(-1 + i\sqrt{3}) + a + ib = 0$

$1 - 2i\sqrt{3} - 3 - ia - a\sqrt{3} + a + ib = 0$

$(-2 - a\sqrt{3} + a) + (-2\sqrt{3} - a + b)i = 0$

ផ្ទឹមផ្នែកពិត និងផ្នែកនិម្មិត យើងបានប្រព័ន្ធសមីការ៖

$\begin{cases} -2 - a\sqrt{3} + a = 0 \\ -2\sqrt{3} - a + b = 0 \end{cases} \Rightarrow \begin{cases} a(1-\sqrt{3}) = 2 \\ b = a + 2\sqrt{3} \end{cases}$

$a = \frac{2}{1-\sqrt{3}} = \frac{2(1+\sqrt{3})}{1-3} = -1-\sqrt{3}$

$b = -1-\sqrt{3} + 2\sqrt{3} = -1+\sqrt{3}$

ដូចនេះ $a = -1-\sqrt{3}$ និង $b = -1+\sqrt{3}$

តាមទ្រឹស្តីបទវីយ៉ែត៖ $z_1 + z_2 = -ia = -i(-1-\sqrt{3}) = i + i\sqrt{3}$

$z_2 = i + i\sqrt{3} - z_1 = i + i\sqrt{3} - (-1 + i\sqrt{3}) = 1 + i$

ឫសមួយទៀតគឺ $z_2 = 1 + i$

ខ. សរសេរជាទម្រង់ត្រីកោណមាត្រ៖

$z_1 = -1 + i\sqrt{3} = 2\left(-\frac{1}{2} + i\frac{\sqrt{3}}{2}\right) = 2\left(\cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3}\right)$

$z_2 = 1 + i = \sqrt{2}\left(\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}\right) = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)$

$\frac{z_1}{z_2} = \frac{2}{\sqrt{2}}\left[\cos\left(\frac{2\pi}{3} - \frac{\pi}{4}\right) + i\sin\left(\frac{2\pi}{3} - \frac{\pi}{4}\right)\right] = \sqrt{2}\left(\cos\frac{5\pi}{12} + i\sin\frac{5\pi}{12}\right)$

ដូចនេះ $\frac{z_1}{z_2} = \sqrt{2}\left(\cos\frac{5\pi}{12} + i\sin\frac{5\pi}{12}\right)$

គ. ទាញរកតម្លៃប្រាកដនៃ $\cos\frac{5\pi}{12}$ និង $\sin\frac{5\pi}{12}$៖

តាមទម្រង់ពីជគណិត៖ $\frac{z_1}{z_2} = \frac{-1+i\sqrt{3}}{1+i} = \frac{(-1+i\sqrt{3})(1-i)}{2} = \frac{\sqrt{3}-1}{2} + i\frac{\sqrt{3}+1}{2}$

ផ្ទឹមទម្រង់ទាំងពីរ យើងបាន៖

$\sqrt{2}\cos\frac{5\pi}{12} = \frac{\sqrt{3}-1}{2} \Rightarrow \cos\frac{5\pi}{12} = \frac{\sqrt{6}-\sqrt{2}}{4}$

$\sqrt{2}\sin\frac{5\pi}{12} = \frac{\sqrt{3}+1}{2} \Rightarrow \sin\frac{5\pi}{12} = \frac{\sqrt{6}+\sqrt{2}}{4}$

លំហាត់ II

គណនាលីមីតខាងក្រោម៖

ក. $\lim_{x \to 1} \left( \frac{1}{1-\sqrt{x}} - \frac{2}{1-x} \right)$

ខ. $\lim_{x \to 0} \frac{e^x - e^{-x}}{\ln(1+x)}$

គ. $\lim_{x \to 0} \frac{\sin[\sin(\sin x)]}{x}$

ដំណោះស្រាយ

ក. $\lim_{x \to 1} \left( \frac{1}{1-\sqrt{x}} - \frac{2}{1-x} \right)$

$= \lim_{x \to 1} \left( \frac{1+\sqrt{x}}{(1-\sqrt{x})(1+\sqrt{x})} - \frac{2}{1-x} \right) = \lim_{x \to 1} \frac{1+\sqrt{x}-2}{1-x}$

$= \lim_{x \to 1} \frac{\sqrt{x}-1}{1-x} = \lim_{x \to 1} \frac{-(1-\sqrt{x})}{(1-\sqrt{x})(1+\sqrt{x})} = \lim_{x \to 1} \frac{-1}{1+\sqrt{x}} = -\frac{1}{2}$

ខ. $\lim_{x \to 0} \frac{e^x - e^{-x}}{\ln(1+x)}$

$= \lim_{x \to 0} \frac{e^{-x}(e^{2x}-1)}{\ln(1+x)} = \lim_{x \to 0} e^{-x} \cdot \frac{e^{2x}-1}{2x} \cdot \frac{x}{\ln(1+x)} \cdot 2$

$= e^0 \cdot 1 \cdot 1 \cdot 2 = 2$

គ. $\lim_{x \to 0} \frac{\sin[\sin(\sin x)]}{x}$

$= \lim_{x \to 0} \frac{\sin[\sin(\sin x)]}{\sin(\sin x)} \cdot \frac{\sin(\sin x)}{\sin x} \cdot \frac{\sin x}{x}$

$= 1 \cdot 1 \cdot 1 = 1$

លំហាត់ III

ក្នុងថ្នាក់រៀនមួយមានសិស្សសរុប ៣៥នាក់ ដែលក្នុងនោះសិស្សប្រុសមាន ២ភាគបីនៃសិស្សស្រី។ គេជ្រើសរើសសិស្ស ៣នាក់ដោយចៃដន្យដើម្បីចូលរួមក្នុងសិក្ខាសាលាមួយស្តីពីបរិស្ថាន។ រកប្រូបាបនៃព្រឹត្តិការណ៍៖

ក. ជ្រើសរើសបានសិស្សស្រីទាំងបីនាក់។

ខ. ជ្រើសរើសបានសិស្សប្រុសពីរនាក់ និងសិស្សស្រីម្នាក់។

គ. ជ្រើសរើសបានយ៉ាងតិចសិស្សប្រុសម្នាក់។

ដំណោះស្រាយ

រកចំនួនសិស្សប្រុស និងសិស្សស្រី៖ តាង $F$ ជាចំនួនសិស្សស្រី នោះចំនួនសិស្សប្រុសគឺ $M = \frac{2}{3}F$ ។

យើងមាន $M + F = 35 \Rightarrow \frac{2}{3}F + F = 35 \Rightarrow \frac{5}{3}F = 35 \Rightarrow F = 21$

ដូចនេះ សិស្សស្រីមាន ២១នាក់ និងសិស្សប្រុសមាន $35 - 21 = 14$ នាក់។

ចំនួនករណីអាច $n(S) = C(35, 3) = \frac{35 \times 34 \times 33}{3 \times 2 \times 1} = 6545$

ក. $A$: ជ្រើសរើសបានសិស្សស្រីទាំង ៣ នាក់

$n(A) = C(21, 3) = \frac{21 \times 20 \times 19}{6} = 1330$

$P(A) = \frac{1330}{6545} = \frac{38}{187}$

ខ. $B$: ជ្រើសរើសបានសិស្សប្រុស ២ នាក់ និងសិស្សស្រី ១ នាក់

$n(B) = C(14, 2) \times C(21, 1) = \frac{14 \times 13}{2} \times 21 = 91 \times 21 = 1911$

$P(B) = \frac{1911}{6545} = \frac{273}{935}$

គ. $C$: ជ្រើសរើសបានយ៉ាងតិចសិស្សប្រុស ១ នាក់

ព្រឹត្តិការណ៍ផ្ទុយនៃ $C$ គឺ "គ្មានសិស្សប្រុសសោះ" ពោលគឺជ្រើសបានសិស្សស្រីទាំង ៣ នាក់ ដែលជាព្រឹត្តិការណ៍ $A$ ។

$P(C) = 1 - P(A) = 1 - \frac{38}{187} = \frac{149}{187}$

លំហាត់ IV

១. គណនាអាំងតេក្រាលខាងក្រោម៖

ក. $I = \int_1^2 \frac{2x+3}{x^2+3x+1} dx$

ខ. $J = \int_e^{e^2} \frac{dx}{x \ln x}$

២. រកចម្លើយមួយនៃសមីការ $(E): y'' - 2y' + 2y = 0$ ដោយដឹងថា $y'(0) = 2$ និង $y(0) = 1$ ។

ដំណោះស្រាយ

១. គណនាអាំងតេក្រាល៖

ក. $I = \int_1^2 \frac{2x+3}{x^2+3x+1} dx$

តាង $u = x^2+3x+1 \Rightarrow du = (2x+3)dx$

$I = \int \frac{du}{u} = [\ln|x^2+3x+1|]_1^2 = \ln(2^2+3(2)+1) - \ln(1^2+3(1)+1) = \ln 11 - \ln 5 = \ln\frac{11}{5}$

ខ. $J = \int_e^{e^2} \frac{dx}{x \ln x}$

តាង $v = \ln x \Rightarrow dv = \frac{1}{x}dx$

$J = \int \frac{dv}{v} = [\ln|\ln x|]_e^{e^2} = \ln(\ln e^2) - \ln(\ln e) = \ln 2 - \ln 1 = \ln 2$

២. ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែល៖

$(E): y'' - 2y' + 2y = 0$ មានសមីការសម្គាល់ $r^2 - 2r + 2 = 0$

$\Delta' = (-1)^2 - 2 = -1 = i^2 \Rightarrow r = 1 \pm i$ (ឫសកុំផ្លិចឆ្លាស់ $\alpha = 1, \beta = 1$)

ចម្លើយទូទៅគឺ $y = e^x(A \cos x + B \sin x)$ ដែល $A, B \in \mathbb{R}$

ដោយ $y(0) = 1 \Rightarrow e^0(A(1) + B(0)) = 1 \Rightarrow A = 1$

យើងមាន $y' = e^x(A \cos x + B \sin x) + e^x(-A \sin x + B \cos x) = e^x((A+B)\cos x + (B-A)\sin x)$

ដោយ $y'(0) = 2 \Rightarrow e^0(A+B) = 2 \Rightarrow 1+B = 2 \Rightarrow B = 1$

ដូចនេះ ចម្លើយគឺ $y = e^x(\cos x + \sin x)$

លំហាត់ V

១. គេឱ្យសមីការអ៊ីពែបូល $\frac{x^2}{9} - \frac{y^2}{4} = 1$ ។ រកកូអរដោនេផ្ចិត កំពូល កំណុំ សមីការអាស៊ីមតូត រួចសង់អ៊ីពែបូលនេះ។

២. ក្នុងតម្រុយមានទិសដៅវិជ្ជមាន $(O, \vec{i}, \vec{j}, \vec{k})$ គេមានបួនចំណុច $A(0, 2, 1); B(2, 0, 2); C(1, 4, 3)$ និង $D(-1, 2, 0)$ ។

ក. បង្ហាញថា $ABC$ ជាត្រីកោណសមបាតកំពូល $A$ ។

ខ. គណនា $\vec{AB} \times \vec{AC}$ និងក្រឡាផ្ទៃត្រីកោណ $ABC$ ។ តើបួនចំណុច $A, B, C, D$ អាចបង្កើតបានចតុមមុខមួយឬទេ?

គ. គណនា $\vec{AD} \cdot \vec{BC}$ រួចបង្ហាញថា $(AD)$ ជាកន្លះបន្ទាត់ពុះនៃមុំ $\angle BAC$ ។

ឃ. រកកូអរដោនេចំណុច $E$ ដោយដឹងថា $\vec{AE} = \frac{1}{3}(\vec{AB} \times \vec{AC})$ ។ គណនាមាឌតេត្រាអែត $EABC$ ។

ដំណោះស្រាយ

១. សិក្សាអ៊ីពែបូល $\frac{x^2}{9} - \frac{y^2}{4} = 1$៖

មានទម្រង់ស្តង់ដា $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ នាំឱ្យ $a=3, b=2$ ។ អ័ក្សទទឹងស្របអ័ក្ស $x'Ox$ ។

$c^2 = a^2 + b^2 = 9 + 4 = 13 \Rightarrow c = \sqrt{13}$

  • ផ្ចិត៖ $I(0, 0)$
  • កំពូល៖ $V_1(-3, 0)$ និង $V_2(3, 0)$
  • កំណុំ៖ $F_1(-\sqrt{13}, 0)$ និង $F_2(\sqrt{13}, 0)$
  • អាស៊ីមតូត៖ $y = \pm\frac{b}{a}x = \pm\frac{2}{3}x$

ក្រាបអ៊ីពែបូល $\frac{x^2}{9} - \frac{y^2}{4} = 1$

២. ក. បង្ហាញថា $ABC$ ជាត្រីកោណសមបាតកំពូល $A$៖

$\vec{AB} = (2-0, 0-2, 2-1) = (2, -2, 1)$ $\Rightarrow |\vec{AB}| = \sqrt{2^2 + (-2)^2 + 1^2} = \sqrt{9} = 3$

$\vec{AC} = (1-0, 4-2, 3-1) = (1, 2, 2)$ $\Rightarrow |\vec{AC}| = \sqrt{1^2 + 2^2 + 2^2} = \sqrt{9} = 3$

ដោយ $|\vec{AB}| = |\vec{AC}| = 3$ នាំឱ្យ $ABC$ ជាត្រីកោណសមបាតកំពូល $A$ ។

ខ. គណនា $\vec{AB} \times \vec{AC}$ និងក្រឡាផ្ទៃ $ABC$៖

$\vec{AB} \times \vec{AC} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 2 & -2 & 1 \\ 1 & 2 & 2 \end{vmatrix} = (-4-2)\vec{i} - (4-1)\vec{j} + (4-(-2))\vec{k} = -6\vec{i} - 3\vec{j} + 6\vec{k} = (-6, -3, 6)$

ក្រឡាផ្ទៃ $S_{ABC} = \frac{1}{2}|\vec{AB} \times \vec{AC}| = \frac{1}{2}\sqrt{(-6)^2 + (-3)^2 + 6^2} = \frac{1}{2}\sqrt{36+9+36} = \frac{1}{2}\sqrt{81} = \frac{9}{2}$ ឯកតាផ្ទៃ។

តើបួនចំណុច $A, B, C, D$ អាចបង្កើតបានចតុមមុខមួយឬទេ?

វ៉ិចទ័រ $\vec{AD} = (-1-0, 2-2, 0-1) = (-1, 0, -1)$ ។

មាឌចតុមមុខ $V = \frac{1}{6}|(\vec{AB} \times \vec{AC}) \cdot \vec{AD}|$

ដោយ $(\vec{AB} \times \vec{AC}) \cdot \vec{AD} = (-6)(-1) + (-3)(0) + (6)(-1) = 6 + 0 - 6 = 0$

នាំឱ្យ $V = \frac{1}{6} \times 0 = 0$ (ការឧបមាមិនពិត) មានន័យថាបួនចំណុច $A, B, C, D$ មិនអាចបង្កើតបានចតុមមុខមួយទេ។

គ. គណនា $\vec{AD} \cdot \vec{BC}$ រួចបង្ហាញថា $(AD)$ ជាកន្លះបន្ទាត់ពុះនៃមុំ $\angle BAC$៖

$\vec{BC} = (1-2, 4-0, 3-2) = (-1, 4, 1)$

$\vec{AD} \cdot \vec{BC} = (-1)(-1) + (0)(4) + (-1)(1) = 1 + 0 - 1 = 0$ នាំឱ្យ $(AD) \perp (BC)$

ដោយ $(AD) \perp (BC)$ នាំឱ្យ $AD$ ជាកម្ពស់នៃត្រីកោណ $ABC$។

ម្យ៉ាងទៀត $ABC$ ជាត្រីកោណសមបាតកំពូល $A$ នាំឱ្យ $(AD)$ ជាកន្លះបន្ទាត់ពុះនៃមុំ $\angle BAC$ ។

ឃ. រកកូអរដោនេចំណុច $E$ រួចគណនាមាឌតេត្រាអែត $EABC$៖

តាង $E(a,b,c)$ នាំឱ្យ $\vec{AE} = (a, b-2, c-1)$

ដោយដឹងថា $\vec{AE} = \frac{1}{3}(\vec{AB} \times \vec{AC})$ និង $\vec{AB} \times \vec{AC} = (-6, -3, 6)$ នោះយើងបាន៖

$(a, b-2, c-1) = \frac{1}{3}(-6, -3, 6) = (-2, -1, 2)$

នាំឱ្យ $\begin{cases} a = -2 \\ b - 2 = -1 \\ c - 1 = 2 \end{cases} \Rightarrow \begin{cases} a = -2 \\ b = 1 \\ c = 3 \end{cases}$

ដូចនេះ កូអរដោនេចំណុច $E(-2, 1, 3)$

ម្យ៉ាងទៀត $V_{EABC} = \frac{1}{6}|(\vec{AB} \times \vec{AC}) \cdot \vec{AE}|$

ដោយ $\vec{AB} \times \vec{AC} = (-6, -3, 6)$ និង $\vec{AE} = (-2, -1, 2)$

នាំឱ្យ $(\vec{AB} \times \vec{AC}) \cdot \vec{AE} = (-6)(-2) + (-3)(-1) + (6)(2) = 12 + 3 + 12 = 27$

យើងបាន $V_{EABC} = \frac{1}{6} \times 27 = \frac{9}{2}$ ឯកតាមាឌ។

លំហាត់ VI

ផ្នែក A: គេមានអនុគមន៍ $f(x) = x - 1 + \ln x$ ចំពោះគ្រប់ $x > 0$ ។

ក. បង្ហាញថា $f'(x) > 0$ ។

ខ. គណនា $f(1)$ រួចសិក្សាសញ្ញានៃ $f(x)$ (មិនបាច់រកលីមីតចុងដែនកំណត់)។

ផ្នែក B: គេឱ្យអនុគមន៍ $g(x) = 1 - \ln x + \frac{\ln x}{x}$ ចំពោះគ្រប់ $x > 0$ ។

ក. គណនាលីមីតចុងដែនកំណត់នៃ $g$ រួចទាញរកអាស៊ីមតូតនៃក្រាប $(C)$ តាងអនុគមន៍ $g$ ។

ខ. បង្ហាញថា $g'(x) = -\frac{f(x)}{x^2}$ ។ ទាញរកសញ្ញានៃ $g'(x)$ ។ គូសតារាងអថេរភាព $g$ ។

គ. គណនា $g(1/e), g(3)$ និង $g(4)$ ។ ទាញបញ្ជាក់ថាក្រាប $(C)$ កាត់អ័ក្សអាប់ស៊ីសត្រង់ $\alpha$ និង $\beta$ ដែល $1/e < \alpha < 1$ និង $3 < \beta < 4$ ។

ឃ. សង់ក្រាប $(C)$ ។

ដំណោះស្រាយ

ផ្នែក A:

ក. $f'(x) = 1 + \frac{1}{x}$ ។ ដោយ $x > 0$ ជានិច្ច នាំឱ្យ $f'(x) > 0$ ចំពោះគ្រប់ $x > 0$ ។

ខ. $f(1) = 1 - 1 + \ln 1 = 0$ ។

ដោយ $f$ ជាអនុគមន៍កើនជានិច្ចលើ $(0, +\infty)$ នាំឱ្យ៖

  • បើ $0 < x < 1$ នោះ $f(x) < f(1) \Rightarrow f(x) < 0$
  • បើ $x = 1$ នោះ $f(x) = 0$
  • បើ $x > 1$ នោះ $f(x) > f(1) \Rightarrow f(x) > 0$

ផ្នែក B:

ក. $\lim_{x \to 0^+} g(x) = \lim_{x \to 0^+} \left(1 - \ln x + \frac{\ln x}{x}\right) = \lim_{x \to 0^+} \left(1 + \ln x\left(\frac{1}{x}-1\right)\right) = 1 + (-\infty)(+\infty) = -\infty$

$\lim_{x \to +\infty} g(x) = \lim_{x \to +\infty} \left(1 - \ln x + \frac{\ln x}{x}\right) = 1 - \infty + 0 = -\infty$

ដោយ $\lim_{x \to 0^+} g(x) = -\infty$ នាំឱ្យបន្ទាត់ $x = 0$ ជាអាស៊ីមតូតឈរ។

ខ. $g'(x) = -\frac{1}{x} + \frac{(\ln x)' x - (x)' \ln x}{x^2} = -\frac{1}{x} + \frac{1 - \ln x}{x^2} = \frac{-x + 1 - \ln x}{x^2} = -\frac{(x - 1 + \ln x)}{x^2} = -\frac{f(x)}{x^2}$

ដោយ $x^2 > 0$ ជានិច្ច នាំឱ្យ $g'(x)$ មានសញ្ញាផ្ទុយពី $f(x)$ ៖

  • $0 < x < 1 \Rightarrow g'(x) > 0$
  • $x = 1 \Rightarrow g'(x) = 0$
  • $x > 1 \Rightarrow g'(x) < 0$

តារាងអថេរភាព៖ អនុគមន៍កើនពី $-\infty$ ទៅ $g(1) = 1 - 0 + 0 = 1$ ត្រង់ $x=1$ រួចចុះទៅ $-\infty$ ។

គ. $g(1/e) = 1 - \ln(e^{-1}) + \frac{\ln(e^{-1})}{1/e} = 1 - (-1) - e = 2 - e \approx 2 - 2.718 = -0.718$

$g(3) = 1 - \ln 3 + \frac{\ln 3}{3} \approx 1 - 1.1 + \frac{1.1}{3} \approx 1 - 1.1 + 0.36 = 0.26$

$g(4) = 1 - \ln 4 + \frac{\ln 4}{4} \approx 1 - 1.38 + \frac{1.38}{4} \approx 1 - 1.38 + 0.345 = -0.035$

ដោយ $g(1/e) < 0$ និង $g(1) = 1 > 0$ នោះក្រាបកាត់អ័ក្ស $Ox$ ត្រង់ចំណុចដែលមានអាប់ស៊ីស $\alpha \in (1/e, 1)$។

ដោយ $g(3) > 0$ និង $g(4) < 0$ នោះក្រាបកាត់អ័ក្ស $Ox$ ត្រង់ចំណុចដែលមានអាប់ស៊ីស $\beta \in (3, 4)$។

ក្រាប $(C)$ តាងអនុគមន៍ $g$
