វិញ្ញាសា គណិតវិទ្យា (វិទ្យាសាស្ត្រពិត) ០៥

សម្រាប់ការត្រៀមប្រឡងសញ្ញាបត្រមធ្យមសិក្សាទុតិយភូមិ

រយៈពេល៖ ១៥០ នាទី ពិន្ទុសរុប៖ ១២៥ ពិន្ទុ

លំហាត់ I (១៥ ពិន្ទុ)

គណនាលីមីតខាងក្រោម៖

ក) $\lim_{x \to 1} \frac{\sqrt[3]{2-x} - \sqrt[3]{x}}{1-x}$

ខ) $\lim_{x \to 0} \frac{1 + x^2 - \cos 4x}{3x^2}$

គ) $\lim_{x \to 0} \frac{e^{3x} + e^{5x} - 2}{4x}$

ដំណោះស្រាយ

ក) គណនាលីមីត $\lim_{x \to 1} \frac{\sqrt[3]{2-x} - \sqrt[3]{x}}{1-x}$

មានរាងមិនកំណត់ $\frac{0}{0}$

គុណនឹងកន្សោមបំបាត់ឫសគូប៖

$= \lim_{x \to 1} \frac{(\sqrt[3]{2-x} - \sqrt[3]{x})[(\sqrt[3]{2-x})^2 + \sqrt[3]{2-x}\cdot\sqrt[3]{x} + (\sqrt[3]{x})^2]}{(1-x)[(\sqrt[3]{2-x})^2 + \sqrt[3]{2-x}\cdot\sqrt[3]{x} + (\sqrt[3]{x})^2]}$

$= \lim_{x \to 1} \frac{(\sqrt[3]{2-x})^3 - (\sqrt[3]{x})^3}{(1-x)[(\sqrt[3]{2-x})^2 + \sqrt[3]{2-x}\cdot\sqrt[3]{x} + (\sqrt[3]{x})^2]}$

$= \lim_{x \to 1} \frac{(2-x) - x}{(1-x)[...]} = \lim_{x \to 1} \frac{2(1-x)}{(1-x)[(\sqrt[3]{2-x})^2 + \sqrt[3]{2-x}\cdot\sqrt[3]{x} + (\sqrt[3]{x})^2]}$

$= \frac{2}{1 + 1 + 1} = \frac{2}{3}$

ដូចនេះ $\lim_{x \to 1} \frac{\sqrt[3]{2-x} - \sqrt[3]{x}}{1-x} = \frac{2}{3}$

ខ) គណនាលីមីត $\lim_{x \to 0} \frac{1 + x^2 - \cos 4x}{3x^2}$

មានរាងមិនកំណត់ $\frac{0}{0}$

$= \lim_{x \to 0} \left( \frac{x^2}{3x^2} + \frac{1 - \cos 4x}{3x^2} \right) = \lim_{x \to 0} \left( \frac{1}{3} + \frac{2\sin^2 2x}{3x^2} \right)$

$= \lim_{x \to 0} \left[ \frac{1}{3} + \left( \frac{\sin 2x}{2x} \right)^2 \times \frac{4 \times 2}{3} \right]$

$= \frac{1}{3} + (1)^2 \times \frac{8}{3} = \frac{9}{3} = 3$

ដូចនេះ $\lim_{x \to 0} \frac{1 + x^2 - \cos 4x}{3x^2} = 3$

គ) គណនាលីមីត $\lim_{x \to 0} \frac{e^{3x} + e^{5x} - 2}{4x}$

មានរាងមិនកំណត់ $\frac{0}{0}$

$= \lim_{x \to 0} \frac{(e^{3x} - 1) + (e^{5x} - 1)}{4x}$

$= \lim_{x \to 0} \left( \frac{e^{3x} - 1}{4x} + \frac{e^{5x} - 1}{4x} \right) = \frac{3}{4} + \frac{5}{4} = \frac{8}{4} = 2$

ដូចនេះ $\lim_{x \to 0} \frac{e^{3x} + e^{5x} - 2}{4x} = 2$

លំហាត់ II (១៥ ពិន្ទុ)

គេឱ្យចំនួនកុំផ្លិច $z = \sqrt{2+\sqrt{2}} + i\sqrt{2-\sqrt{2}}$ ។

ក) ចូរសរសេរ $z^2$ ជាទម្រង់ពីជគណិត។

ខ) ចូរសរសេរ $z^2$ និង $z$ ជាទម្រង់ត្រីកោណមាត្រ។

គ) ទាញរកតម្លៃប្រាកដនៃ $\cos \frac{\pi}{8}$ និង $\sin \frac{\pi}{8}$ ។

ដំណោះស្រាយ

ក) សរសេរ $z^2$ ជាទម្រង់ពីជគណិត៖

$z^2 = (\sqrt{2+\sqrt{2}} + i\sqrt{2-\sqrt{2}})^2$

$= (\sqrt{2+\sqrt{2}})^2 + 2i\sqrt{2+\sqrt{2}}\sqrt{2-\sqrt{2}} + (i\sqrt{2-\sqrt{2}})^2$

$= 2+\sqrt{2} + 2i\sqrt{(2+\sqrt{2})(2-\sqrt{2})} - (2-\sqrt{2})$

$= 2\sqrt{2} + 2i\sqrt{4-2} = 2\sqrt{2} + 2i\sqrt{2}$

ដូចនេះ $z^2 = 2\sqrt{2} + 2i\sqrt{2}$

ខ) សរសេរ $z^2$ និង $z$ ជាទម្រង់ត្រីកោណមាត្រ៖

$z^2 = 2\sqrt{2} + 2i\sqrt{2} = 4(\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}) = 4(\cos \frac{\pi}{4} + i\sin \frac{\pi}{4})$

ដោយ $z^2 = 4[\cos(\frac{\pi}{4} + 2k\pi) + i\sin(\frac{\pi}{4} + 2k\pi)]$

នាំឱ្យ $z_k = 2\left( \cos \frac{\pi + 8k\pi}{8} + i\sin \frac{\pi + 8k\pi}{8} \right)$ ដែល $k = 0, 1$

  • បើ $k=0 \Rightarrow z_0 = 2\left( \cos \frac{\pi}{8} + i\sin \frac{\pi}{8} \right)$
  • បើ $k=1 \Rightarrow z_1 = 2\left( \cos \frac{9\pi}{8} + i\sin \frac{9\pi}{8} \right)$ (មិនយក ព្រោះ $z$ មានផ្នែកពិតនិងនិម្មិតវិជ្ជមាន)
ដូចនេះ $z^2 = 4\left( \cos \frac{\pi}{4} + i\sin \frac{\pi}{4} \right)$ និង $z = 2\left( \cos \frac{\pi}{8} + i\sin \frac{\pi}{8} \right)$

គ) ទាញរកតម្លៃប្រាកដនៃ $\cos \frac{\pi}{8}$ និង $\sin \frac{\pi}{8}$៖

ដោយ $z = \sqrt{2+\sqrt{2}} + i\sqrt{2-\sqrt{2}}$ និង $z = 2\left( \cos \frac{\pi}{8} + i\sin \frac{\pi}{8} \right)$

ផ្ទឹមផ្នែកពិត និងនិម្មិត យើងបាន៖

$2\cos \frac{\pi}{8} = \sqrt{2+\sqrt{2}} \Rightarrow \cos \frac{\pi}{8} = \frac{\sqrt{2+\sqrt{2}}}{2}$

$2\sin \frac{\pi}{8} = \sqrt{2-\sqrt{2}} \Rightarrow \sin \frac{\pi}{8} = \frac{\sqrt{2-\sqrt{2}}}{2}$

ដូចនេះ $\cos \frac{\pi}{8} = \frac{\sqrt{2+\sqrt{2}}}{2}$ និង $\sin \frac{\pi}{8} = \frac{\sqrt{2-\sqrt{2}}}{2}$

លំហាត់ III (១៥ ពិន្ទុ)

១) គេឱ្យអនុគមន៍ $f(x) = \frac{1}{x^2-1}$ ចំពោះគ្រប់ $x \neq \pm 1$ ។

ក) កំណត់ $A, B$ ដើម្បីឱ្យ $f(x) = \frac{A}{x-1} + \frac{B}{x+1}$ ។

ខ) គណនា $I = \int_2^5 f(x) dx$ ។

២) គេឱ្យសមីការឌីផេរ៉ង់ស្យែល $(E): 2y'' - 3y' + y = 8$ ។

ក) កំណត់ចំនួនពិត $k$ ដើម្បីឱ្យ $y_1 = k$ ជាចម្លើយនៃ $(E)$ ។

ខ) ដោះស្រាយរក $y_2$ ដែលជាចម្លើយនៃ $(F): 2y'' - 3y' + y = 0$ ។

គ) ទាញរកចម្លើយទូទៅនៃ $(E)$ ។

ដំណោះស្រាយ

១) ក) កំណត់ $A, B$៖

យើងមាន $\frac{1}{x^2-1} = \frac{A(x+1) + B(x-1)}{(x-1)(x+1)} = \frac{(A+B)x + (A-B)}{x^2-1}$

ផ្ទឹមមេគុណ យើងបាន $\begin{cases} A+B = 0 \\ A-B = 1 \end{cases} \Rightarrow 2A = 1 \Rightarrow A = \frac{1}{2}, B = -\frac{1}{2}$

ដូចនេះ $A = \frac{1}{2}, B = -\frac{1}{2}$

១) ខ) គណនា $I = \int_2^5 f(x) dx$៖

$I = \int_2^5 \left( \frac{1/2}{x-1} - \frac{1/2}{x+1} \right) dx = \frac{1}{2} \left[ \ln|x-1| - \ln|x+1| \right]_2^5$

$= \frac{1}{2} \left[ \ln \frac{x-1}{x+1} \right]_2^5 = \frac{1}{2} \left( \ln \frac{4}{6} - \ln \frac{1}{3} \right) = \frac{1}{2} \left( \ln \frac{2}{3} - \ln \frac{1}{3} \right) = \frac{1}{2} \ln 2$

ដូចនេះ $I = \frac{1}{2} \ln 2$

២) ក) កំណត់ចំនួនពិត $k$៖

$y_1 = k$ ជាចំនួនថេរ នាំឱ្យ $y_1' = 0, y_1'' = 0$

ជំនួសចូល $(E)$: $2(0) - 3(0) + k = 8 \Rightarrow k = 8$

ដូចនេះ $k = 8$

២) ខ) ដោះស្រាយ $(F): 2y'' - 3y' + y = 0$៖

សមីការសម្គាល់៖ $2\lambda^2 - 3\lambda + 1 = 0 \Rightarrow \lambda_1 = 1, \lambda_2 = \frac{1}{2}$

ដូចនេះ ចម្លើយនៃ $(F)$ គឺ $y_2 = Ae^x + Be^{\frac{1}{2}x}$ ដែល $A, B \in \mathbb{R}$

២) គ) ទាញរកចម្លើយទូទៅនៃ $(E)$៖

ចម្លើយទូទៅនៃ $(E)$ គឺ $y = y_2 + y_1$

ដូចនេះ $y = Ae^x + Be^{\frac{1}{2}x} + 8$ ដែល $A, B \in \mathbb{R}$

លំហាត់ IV (១៥ ពិន្ទុ)

ប្ដីប្រពន្ធមួយគូមានបំណងយកកូនពីរនាក់។ ដោយសង្កេតថាលទ្ធភាពដែលអាចមានកូនប្រុស ឬកូនស្រីមានប្រូបាបស្មើគ្នា។ រកប្រូបាបនៃព្រឹត្តិការណ៍៖

ក) A: បានកូនប្រុសទាំងពីរនាក់

ខ) B: បានកូនស្រីនៅលើកទីមួយ

គ) C: បានកូនទាំងពីរមានភេទខុសគ្នា

ដំណោះស្រាយ

តាង B ជាកូនប្រុស និង G ជាកូនស្រី។ ករណីអាចកើតមានទាំងអស់គឺ៖

$S = \{(B,B), (B,G), (G,B), (G,G)\} \Rightarrow n(S) = 4$

ក) A: បានកូនប្រុសទាំងពីរនាក់

$A = \{(B,B)\} \Rightarrow n(A) = 1$

$P(A) = \frac{1}{4}$

ដូចនេះ $P(A) = \frac{1}{4}$

ខ) B: បានកូនស្រីនៅលើកទីមួយ

$B = \{(G,B), (G,G)\} \Rightarrow n(B) = 2$

$P(B) = \frac{2}{4} = \frac{1}{2}$

ដូចនេះ $P(B) = \frac{1}{2}$

គ) C: បានកូនទាំងពីរមានភេទខុសគ្នា

$C = \{(B,G), (G,B)\} \Rightarrow n(C) = 2$

$P(C) = \frac{2}{4} = \frac{1}{2}$

ដូចនេះ $P(C) = \frac{1}{2}$

លំហាត់ V (១៥ ពិន្ទុ)

គេឱ្យសមីការអេលីប $(E): 16x^2 + 25y^2 - 32x - 50y - 359 = 0$ ។

ក) រកសមីការស្តង់ដាអេលីប រួចទាញរកកូអរដោនេផ្ចិត កំពូល និងកំណុំរបស់វា។

ខ) ផ្ទៀងផ្ទាត់ថា $\forall \theta \in \mathbb{R}$ ចំណុច $M(1+5\cos\theta, 1+4\sin\theta)$ ស្ថិតនៅលើអេលីប $(E)$ ។

គ) ស្រាយថាបន្ទាត់ប៉ះ $(E)$ ត្រង់ $M$ មានមេគុណប្រាប់ទិស $k = -\frac{4}{5}\cot\theta$ ។

ដំណោះស្រាយ

ក) រកសមីការស្តង់ដាអេលីប និងរកកូអរដោនេ៖

$(E): 16(x^2 - 2x) + 25(y^2 - 2y) = 359$

$16(x - 1)^2 - 16 + 25(y - 1)^2 - 25 = 359$

$16(x - 1)^2 + 25(y - 1)^2 = 400$

ចែកនឹង $400$ យើងបាន៖ $\frac{(x-1)^2}{25} + \frac{(y-1)^2}{16} = 1$

ដូចនេះ សមីការស្តង់ដាគឺ $\frac{(x-1)^2}{25} + \frac{(y-1)^2}{16} = 1$

តាមសមីការមានរាង $\frac{(x-h)^2}{a^2} + \frac{(y-k)^2}{b^2} = 1$ នាំឱ្យ $h=1, k=1, a=5, b=4$

$c = \sqrt{a^2 - b^2} = \sqrt{25 - 16} = 3$

  • ផ្ចិត៖ $I(h, k) \Rightarrow I(1, 1)$
  • កំណុំ៖ $F_{1,2}(h \pm c, k) \Rightarrow F_1(-2, 1), F_2(4, 1)$
  • កំពូល៖ $V_{1,2}(h \pm a, k) \Rightarrow V_1(-4, 1), V_2(6, 1)$

ខ) ផ្ទៀងផ្ទាត់ចំណុច $M$៖

យកកូអរដោនេ $M(1+5\cos\theta, 1+4\sin\theta)$ ទៅជួសក្នុងសមីការស្តង់ដា៖

$\frac{(1+5\cos\theta - 1)^2}{25} + \frac{(1+4\sin\theta - 1)^2}{16} = \frac{25\cos^2\theta}{25} + \frac{16\sin^2\theta}{16} = \cos^2\theta + \sin^2\theta = 1$ ពិតជានិច្ច $\forall \theta$ ។

ដូចនេះ ចំណុច $M$ ស្ថិតនៅលើអេលីប $(E)$ ជានិច្ច។

គ) ស្រាយថាបន្ទាត់ប៉ះត្រង់ $M$ មាន $k = -\frac{4}{5}\cot\theta$៖

មេគុណប្រាប់ទិសបន្ទាត់ប៉ះគឺ $k = y'(x_M)$

ធ្វើដេរីវេ $(E)$ ធៀបនឹង $x$: $32x + 50yy' - 32 - 50y' = 0$

$y'(50y - 50) = 32 - 32x \Rightarrow y' = \frac{-32(x-1)}{50(y-1)} = -\frac{16(x-1)}{25(y-1)}$

ត្រង់ $M$: $y' = -\frac{16(1+5\cos\theta - 1)}{25(1+4\sin\theta - 1)} = -\frac{16(5\cos\theta)}{25(4\sin\theta)} = -\frac{80\cos\theta}{100\sin\theta} = -\frac{4}{5}\cot\theta$

ដូចនេះ បន្ទាត់ប៉ះត្រង់ $M$ មានមេគុណប្រាប់ទិស $k = -\frac{4}{5}\cot\theta$ ពិត។

លំហាត់ VI (២៥ ពិន្ទុ)

ក្នុងតម្រុយអរតូណរម៉ាល់មានទិសដៅវិជ្ជមាន $(O, \vec{i}, \vec{j}, \vec{k})$ គេឱ្យសមីការប្លង់ $(P): x + 2y + 2z - 4 = 0$ និងចំណុច $I(1, 2, 4)$ ។

ក) កំណត់សមីការប៉ារ៉ាម៉ែត្រនៃបន្ទាត់ $(L)$ ដែលកាត់តាម $I$ ហើយកែងនឹង $(P)$ ត្រង់ $J$ ។ រกกូអរដោនេ $J$ ។

ខ) កំណត់សមីការស៊្វែរ $(S)$ ដែលមានផ្ចិត $I$ ហើយប៉ះទៅនឹងប្លង់ $(P)$ ។

គ) ប្លង់ $(P)$ កាត់អ័ក្ស $(ox), (oy), (oz)$ រៀងគ្នាត្រង់ $A, B, C$ ។ រกกូអរដោនេនៃចំណុច $A, B, C$ និង $\vec{n} = \vec{AB} \times \vec{AC}$ ។

ឃ) គណនាក្រឡាផ្ទៃត្រីកោណ $ABC$ និងមាឌចតុមូល $IABC$ ។

ដំណោះស្រាយ

ក) សមីការប៉ារ៉ាម៉ែត្រនៃ $(L)$ និងកូអរដោនេ $J$៖

បន្ទាត់ $(L) \perp (P)$ នាំឱ្យ $(L)$ មានវ៉ិចទ័រប្រាប់ទិស $\vec{u} = \vec{n}_P = (1, 2, 2)$

បន្ទាត់ $(L)$ កាត់តាម $I(1, 2, 4)$ មានសមីការប៉ារ៉ាម៉ែត្រ៖

$(L): \begin{cases} x = 1 + t \\ y = 2 + 2t \\ z = 4 + 2t \end{cases} \quad (t \in \mathbb{R})$

រក $J = (L) \cap (P)$ ដោយជួសកូអរដោនេ $(L)$ ចូល $(P)$៖

$(1+t) + 2(2+2t) + 2(4+2t) - 4 = 0 \Rightarrow 1+t+4+4t+8+4t-4 = 0 \Rightarrow 9t + 9 = 0 \Rightarrow t = -1$

ជួស $t = -1$ ចូលសមីការ $(L)$ យើងបាន $x = 0, y = 0, z = 2$

ដូចនេះ កូអរដោនេ $J(0, 0, 2)$

ខ) កំណត់សមីការស៊្វែរ $(S)$៖

ស៊្វែរ $(S)$ ប៉ះប្លង់ $(P)$ ត្រង់ $J$ នាំឱ្យកាំ $R = IJ$

$R = \sqrt{(0-1)^2 + (0-2)^2 + (2-4)^2} = \sqrt{1 + 4 + 4} = 3$

សមីការស៊្វែរ $(S): (x-1)^2 + (y-2)^2 + (z-4)^2 = 9$

គ) រกกូអរដោនេ $A, B, C$ និងគណនា $\vec{n}$៖

$(P) \cap (ox) \Rightarrow y=0, z=0 \Rightarrow x - 4 = 0 \Rightarrow A(4,0,0)$

$(P) \cap (oy) \Rightarrow x=0, z=0 \Rightarrow 2y - 4 = 0 \Rightarrow B(0,2,0)$

$(P) \cap (oz) \Rightarrow x=0, y=0 \Rightarrow 2z - 4 = 0 \Rightarrow C(0,0,2)$

$\vec{AB} = (0-4, 2-0, 0-0) = (-4, 2, 0)$ និង $\vec{AC} = (0-4, 0-0, 2-0) = (-4, 0, 2)$

$\vec{n} = \vec{AB} \times \vec{AC} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ -4 & 2 & 0 \\ -4 & 0 & 2 \end{vmatrix} = (4-0)\vec{i} - (-8-0)\vec{j} + (0-(-8))\vec{k} = 4\vec{i} + 8\vec{j} + 8\vec{k}$

ដូចនេះ $A(4,0,0), B(0,2,0), C(0,0,2)$ និង $\vec{n} = (4, 8, 8)$

ឃ) គណនាក្រឡាផ្ទៃ និងមាឌ៖

ក្រឡាផ្ទៃ $S_{ABC} = \frac{1}{2}|\vec{n}| = \frac{1}{2}\sqrt{4^2 + 8^2 + 8^2} = \frac{1}{2}\sqrt{16 + 64 + 64} = \frac{1}{2}\sqrt{144} = 6$ ឯកតាផ្ទៃ

មាឌ $V_{IABC} = \frac{1}{6}|(\vec{AB} \times \vec{AC}) \cdot \vec{AI}|$

ដោយ $\vec{AB} \times \vec{AC} = (4, 8, 8)$ និង $\vec{AI} = (1-4, 2-0, 4-0) = (-3, 2, 4)$

នោះ $(\vec{AB} \times \vec{AC}) \cdot \vec{AI} = (4)(-3) + (8)(2) + (8)(4) = -12 + 16 + 32 = 36$

នាំឱ្យ $V_{IABC} = \frac{1}{6} \times 36 = 6$

ដូចនេះ $S_{ABC} = 6$ ឯកតាផ្ទៃ និង $V_{IABC} = 6$ ឯកតាមាឌ

លំហាត់ VII (២៥ ពិន្ទុ)

$f$ ជាអនុគមន៍កំណត់ដោយ $f(x) = \frac{x}{2} - \ln\left(\frac{x-1}{x}\right)$ និងមានក្រាប $(C)$ ។

ក) រកដែនកំណត់នៃ $f$ ។ គណនាលីមីតចុងដែនកំណត់ រួចទាញរកអាស៊ីមតូតនៃ $(C)$ ។

ខ) បង្ហាញថាបន្ទាត់ $(d): y = \frac{x}{2}$ ជាអាស៊ីមតូតទ្រេតនៃក្រាប $(C)$ ។

គ) គណនា $f'(x)$ សង់តារាងអថេរភាពនៃ $f$ ។

ឃ) សង់ក្រាប $(C)$ និងអាស៊ីមតូតរបស់វាក្នុងតម្រុយតែមួយ។ (គេឱ្យ $\ln 2 = 0.7$)

ដំណោះស្រាយ

ក) រកដែនកំណត់ លីមីត និងអាស៊ីមតូត៖

អនុគមន៍មានន័យកាលណា $\frac{x-1}{x} > 0 \Rightarrow x \in (-\infty, 0) \cup (1, +\infty)$

ដែនកំណត់ $D_f = (-\infty, 0) \cup (1, +\infty)$

លីមីត៖

$\lim_{x \to \pm\infty} f(x) = \lim_{x \to \pm\infty} \left[\frac{x}{2} - \ln\left(\frac{x-1}{x}\right)\right] = \pm\infty$ [$\because \lim_{x \to \pm\infty} \ln\left(\frac{x-1}{x}\right) = \ln 1 = 0$]

$\lim_{x \to 0^-} f(x) = 0 - (+\infty) = -\infty$ [$\because \lim_{x \to 0^-} \ln\left(\frac{x-1}{x}\right) = \ln(\frac{-1}{0^-}) = \ln(+\infty) = +\infty$]

$\lim_{x \to 1^+} f(x) = \frac{1}{2} - (-\infty) = +\infty$ [$\because \lim_{x \to 1^+} \ln\left(\frac{x-1}{x}\right) = \ln(\frac{0^+}{1}) = \ln 0^+ = -\infty$]

តាមរយៈលីមីតខាងលើ បន្ទាត់ $x=0$ និង $x=1$ ជាអាស៊ីមតូតឈរ។

ខ) បង្ហាញថា $(d): y = \frac{x}{2}$ ជាអាស៊ីមតូតទ្រេត៖

ពិនិត្យ $\lim_{x \to \pm\infty} [y_C - y_d] = \lim_{x \to \pm\infty} \left[ -\ln\left(\frac{x-1}{x}\right) \right] = 0$ [$\because$ គណនាដូចខាងលើ]

ដូចនេះ បន្ទាត់ $(d): y = \frac{x}{2}$ ជាអាស៊ីមតូតទ្រេតនៃ $(C)$ នៅ $\pm\infty$។

គ) គណនា $f'(x)$ និងសង់តារាងអថេរភាព៖

$f'(x) = [\frac{x}{2} - \ln\left(\frac{x-1}{x}\right)]' = \frac{1}{2} - \frac{(\frac{x-1}{x})'}{\frac{x-1}{x}} = \frac{1}{2} - \frac{x}{x-1} \cdot \frac{x-(x-1)}{x^2} = \frac{1}{2} - \frac{1}{x(x-1)}$

$= \frac{x(x-1)-2}{2x(x-1)} = \frac{x^2 - x - 2}{2x(x-1)}$

ដោយ $2x(x-1) > 0$ ចំពោះគ្រប់ $x \in D_f$ នាំឱ្យ $f'(x)$ មានសញ្ញាដូចភាគយក $x^2 - x - 2$

យក $f'(x) = 0 \Rightarrow x^2 - x - 2 = 0 \Rightarrow x_1 = -1, x_2 = 2$ [$\because a-b+c=0$]

ដោយ $f'(x)$ ប្តូរសញ្ញាត្រង់ $x=-1$ និង $x=2$ យើងបានតម្លៃបរមាធៀបនៃ $f$ ដូចខាងក្រោម៖

$f(-1) = -\frac{1}{2} - \ln 2 \approx -0.5 - 0.7 = -1.2$

$f(2) = 1 - \ln \frac{1}{2} = 1 + \ln 2 \approx 1 + 0.7 = 1.7$

តារាងអថេរភាព $f$៖

$x$ $-\infty$ $-1$ $0$ $1$ $2$ $+\infty$
$f'(x)$ $+$ $0$ $-$ $-$ $0$ $+$
$f(x)$ $-\infty \nearrow$ $-1.2$ $\searrow -\infty$ $+\infty \searrow$ $1.7$ $\nearrow +\infty$
