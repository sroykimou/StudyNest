វិញ្ញាសា គណិតវិទ្យា (វិទ្យាសាស្ត្រពិត) ១៥

សម្រាប់ការត្រៀមប្រឡងសញ្ញាបត្រមធ្យមសិក្សាទុតិយភូមិ

រយៈពេល៖ ១៥០ នាទី ពិន្ទុសរុប៖ ១២៥ ពិន្ទុ

លំហាត់ I (១០ ពិន្ទុ)

គណនាលីមីត៖

១. $\lim_{x \to 1} \frac{1-x^2}{x^3-x^2+x-1}$

២. $\lim_{x \to 0} \frac{\sin 3x}{-x}$

៣. $\lim_{x \to 0} \frac{\sqrt{2+x}-\sqrt{2-x}}{\sin x}$

ដំណោះស្រាយ

១. $\lim_{x \to 1} \frac{1-x^2}{x^3-x^2+x-1} = \lim_{x \to 1} \frac{-(x-1)(x+1)}{(x-1)(x^2+1)} = \lim_{x \to 1} \frac{-(x+1)}{x^2+1} = \frac{-(1+1)}{1^2+1} = -1$

២. $\lim_{x \to 0} \frac{\sin 3x}{-x} = \lim_{x \to 0} \left(\frac{\sin 3x}{3x} \cdot (-3)\right) = 1 \cdot (-3) = -3$

៣. $\lim_{x \to 0} \frac{\sqrt{2+x}-\sqrt{2-x}}{\sin x} = \lim_{x \to 0} \frac{(\sqrt{2+x}-\sqrt{2-x})(\sqrt{2+x}+\sqrt{2-x})}{\sin x (\sqrt{2+x}+\sqrt{2-x})} = \lim_{x \to 0} \frac{2x}{\sin x (\sqrt{2+x}+\sqrt{2-x})} = 2 \cdot 1 \cdot \frac{1}{2\sqrt{2}} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$

លំហាត់ II (១៥ ពិន្ទុ)

ក្នុងថ្នាក់រៀនមួយមានសិស្សពូកែចំនួន $10$ នាក់ ដែលក្នុងនោះមាន $4$ នាក់ជាសិស្សស្រី និង $6$ នាក់ជាសិស្សប្រុស។ គេរៀបចំសិស្សជាក្រុម ក្នុងមួយក្រុមមាន $4$ នាក់ដោយចៃដន្យយកទៅប្រកួតជាមួយក្រុមសិស្សនៃថ្នាក់ដទៃ។ រកប្រូបាបនៃព្រឹត្តិការណ៍៖

ក. ក្រុមសិស្សដែលជ្រើសរើសបានសុទ្ធតែស្រី។

ខ. ក្រុមសិស្សដែលជ្រើសរើសបានសុទ្ធតែប្រុស។

គ. ក្រុមសិស្សដែលជ្រើសរើសបាន $50\%$ ជាសិស្សប្រុស។

ដំណោះស្រាយ

ចំនួនករណីអាច $n(S) = C(10, 4) = \frac{10!}{4!6!} = 210$

ក. $n(A) = C(4, 4) = 1 \Rightarrow P(A) = \frac{1}{210}$

ខ. $n(B) = C(6, 4) = 15 \Rightarrow P(B) = \frac{15}{210} = \frac{1}{14}$

គ. $50\%$ នៃ $4$ នាក់ គឺ $2$ នាក់។ ដូចនេះមានន័យថាជ្រើសបានប្រុស $2$ ស្រី $2$។

$n(C) = C(6, 2) \cdot C(4, 2) = 15 \cdot 6 = 90 \Rightarrow P(C) = \frac{90}{210} = \frac{3}{7}$

លំហាត់ III (១៥ ពិន្ទុ)

គេឱ្យចំនួនកុំផ្លិច $z_1 = 1 + i\sqrt{3}$ និង $z_2 = 6(\cos \frac{\pi}{4} - i\sin \frac{\pi}{4})$។

ក. សរសេរ $z_1$ ជាទម្រង់ត្រីកោណមាត្រ។

ខ. រកម៉ូឌុល និងអាគុយម៉ង់នៃ $z_1^3$។

គ. សរសេរផលគុណ $z_1 \times z_2$ ជាទម្រង់ពីជគណិត។

ដំណោះស្រាយ

ក. $z_1 = 1 + i\sqrt{3} = 2(\frac{1}{2} + i\frac{\sqrt{3}}{2}) = 2(\cos \frac{\pi}{3} + i\sin \frac{\pi}{3})$

ខ. $z_1^3 = [2(\cos \frac{\pi}{3} + i\sin \frac{\pi}{3})]^3 = 8(\cos \pi + i\sin \pi)$

ម៉ូឌុល $|z_1^3| = 8$, អាគុយម៉ង់ $\text{arg}(z_1^3) = \pi + 2k\pi$

គ. $z_2 = 6(\cos \frac{\pi}{4} - i\sin \frac{\pi}{4}) = 6(\frac{\sqrt{2}}{2} - i\frac{\sqrt{2}}{2}) = 3\sqrt{2} - 3i\sqrt{2}$

$z_1 \times z_2 = (1 + i\sqrt{3})(3\sqrt{2} - 3i\sqrt{2}) = 3\sqrt{2} - 3i\sqrt{2} + 3i\sqrt{6} + 3\sqrt{6} = 3(\sqrt{2}+\sqrt{6}) + 3i(\sqrt{6}-\sqrt{2})$

លំហាត់ IV (២០ ពិន្ទុ)

១. ក្នុងលំហផ្ដល់ដោយតម្រុយ $(O, \vec{i}, \vec{j}, \vec{k})$ គេមានចំណុច $A(-2, 1, 0), B(0, 1, 1), C(1, 2, 2)$ និង $D(0, 3, -4)$។

ក. រកវ៉ិចទ័រ $\vec{AB}, \vec{AC}, \vec{AD}, \vec{BC}, \vec{BD}, \vec{CD}$។

ខ. គណនាប្រវែងជ្រុង រួចបញ្ជាក់ថា $ABD$ និង $ACD$ ជាត្រីកោណកែងត្រង់ $A$។

២. គេមានសមីការ $9y^2 - 16x^2 = 144$។ បង្ហាញថានេះជាសមីការអ៊ីពែបូល រកផ្ចិត កំពូល កំណុំ អាស៊ីមតូត និងសង់វា។

ដំណោះស្រាយ

១. ក. $\vec{AB}=(2, 0, 1), \vec{AC}=(3, 1, 2), \vec{AD}=(2, 2, -4), \vec{BC}=(1, 1, 1), \vec{BD}=(0, 2, -5), \vec{CD}=(-1, 1, -6)$

ខ. $\vec{AB} \cdot \vec{AD} = 2(2) + 0(2) + 1(-4) = 0 \Rightarrow \vec{AB} \perp \vec{AD} \Rightarrow ABD$ កែងត្រង់ $A$

$\vec{AC} \cdot \vec{AD} = 3(2) + 1(2) + 2(-4) = 0 \Rightarrow \vec{AC} \perp \vec{AD} \Rightarrow ACD$ កែងត្រង់ $A$

២. $9y^2 - 16x^2 = 144 \Rightarrow \frac{y^2}{16} - \frac{x^2}{9} = 1 \Rightarrow \frac{y^2}{4^2} - \frac{x^2}{3^2} = 1$

ផ្ចិត $O(0, 0)$, កំពូល $V_1(0, -4), V_2(0, 4)$, កំណុំ $F_1(0, -5), F_2(0, 5)$, អាស៊ីមតូត $y = \pm \frac{4}{3}x$

លំហាត់ V (១៥ ពិន្ទុ)

គណនាអាំងតេក្រាល៖

$I = \int_1^3 (x-2+3x^2)dx$, $J = \int_0^{\pi/4} (\sin 2x - \cos x)dx$, $K = \int_0^1 \frac{x^3+(x+1)^2}{x^2+1}dx$

ដំណោះស្រាយ

$I = [\frac{x^2}{2}-2x+x^3]_1^3 = (\frac{9}{2}-6+27)-(\frac{1}{2}-2+1) = \frac{8}{2}+21+1 = 4+22 = 26$

$J = [-\frac{1}{2}\cos 2x - \sin x]_0^{\pi/4} = (-\frac{1}{2}(0)-\frac{\sqrt{2}}{2})-(-\frac{1}{2}-0) = \frac{1-\sqrt{2}}{2}$

ចំពោះ $K$: $\frac{x^3+x^2+2x+1}{x^2+1} = \frac{x(x^2+1)+(x^2+1)+x}{x^2+1} = x+1+\frac{x}{x^2+1}$

$K = \int_0^1 (x+1+\frac{x}{x^2+1})dx = [\frac{x^2}{2}+x+\frac{1}{2}\ln(x^2+1)]_0^1 = \frac{1}{2}+1+\frac{1}{2}\ln 2 = \frac{3+\ln 2}{2}$

លំហាត់ VI (១០ ពិន្ទុ)

១. ដោះស្រាយសមីការឌីផេរ៉ង់ស្យែល $(E): y'' - 3y' + 2y = 0$។

២. រកចម្លើយពិសេសនៃ $(E)$ ដែល $y(0)=1$ និង $y'(1)=2e^2$។

ដំណោះស្រាយ

១. $r^2-3r+2=0 \Rightarrow r_1=1, r_2=2 \Rightarrow y = Ae^x + Be^{2x}$

២. $y(0)=1 \Rightarrow A+B=1$. $y' = Ae^x+2Be^{2x} \Rightarrow y'(1) = Ae+2Be^2 = 2e^2$

$A+B=1 \Rightarrow A=1-B \Rightarrow (1-B)e+2Be^2=2e^2 \Rightarrow B(2e^2-e) = 2e^2-e \Rightarrow B=1, A=0$

ចម្លើយពិសេស៖ $y = e^{2x}$

លំហាត់ VII (៤០ ពិន្ទុ)

គេមានអនុគមន៍ $f(x) = x + \frac{1-3e^x}{1+e^x}$ និងមានក្រាប $(C)$។

១. បង្ហាញថា $f(x) = x+1-\frac{4e^x}{1+e^x}$ រកលីមីតត្រង់ $-\infty$ បញ្ជាក់អាស៊ីមតូតទ្រេត $d_1: y=x+1$ និងទីតាំងធៀប។

២. រកលីមីតត្រង់ $+\infty$ បញ្ជាក់អាស៊ីមតូតទ្រេត $d_2: y=x-3$ និងទីតាំងធៀប។

៣. គណនាដេរីវេ បង្ហាញថា $f'(x) = (\frac{e^x-1}{e^x+1})^2$, សិក្សាអថេរភាព និងសង់ក្រាប។

ដំណោះស្រាយ

១. $x+\frac{1-3e^x}{1+e^x} = x+\frac{1+e^x-4e^x}{1+e^x} = x+1-\frac{4e^x}{1+e^x}$

$\lim_{x \to -\infty} f(x) = -\infty$. $\lim_{x \to -\infty} [f(x)-(x+1)] = 0 \Rightarrow d_1: y=x+1$ ជាអាស៊ីមតូតទ្រេត។

$f(x)-y_{d1} = -\frac{4e^x}{1+e^x} < 0 \Rightarrow (C)$ នៅក្រោម $d_1$។

២. $\lim_{x \to +\infty} f(x) = +\infty$. $f(x) = x+\frac{1-3e^x}{1+e^x} = x+\frac{e^x(e^{-x}-3)}{e^x(e^{-x}+1)} \Rightarrow \lim_{x \to +\infty} [f(x)-(x-3)] = 0$

$d_2: y=x-3$ ជាអាស៊ីមតូតទ្រេត។ $(C)$ នៅលើ $d_2$។

៣. $f'(x) = 1 - \frac{4e^x(1+e^x)-e^x(4e^x)}{(1+e^x)^2} = 1 - \frac{4e^x}{(1+e^x)^2} = \frac{1+2e^x+e^{2x}-4e^x}{(1+e^x)^2} = \frac{(e^x-1)^2}{(1+e^x)^2} = (\frac{e^x-1}{e^x+1})^2$

$f'(x) \ge 0 \Rightarrow f$ កើនជានិច្ច។ $f'(x)=0 \Leftrightarrow x=0 \Rightarrow f(0)=-1$ (ចំណុចរបត់)។
