វិញ្ញាសា គណិតវិទ្យា (វិទ្យាសាស្ត្រពិត) ០២

សម្រាប់ការត្រៀមប្រឡងសញ្ញាបត្រមធ្យមសិក្សាទុតិយភូមិ

រយៈពេល៖ ១៥០ នាទី ពិន្ទុសរុប៖ ១២៥ ពិន្ទុ

លំហាត់ I (១៥ ពិន្ទុ)

គេឱ្យចំនួនកុំផ្លិច $z_1 = \frac{2\left(\cos\frac{\pi}{12} + i\sin\frac{\pi}{12}\right)^2}{1+i\sqrt{3}}$ និង $z_2 = (1-i)x + (1-y)(1+i)$ ។

ក. សរសេរ $z_1$ ជាទម្រង់ត្រីកោណមាត្រ រួចជាទម្រង់ពីជគណិត។

ខ. កំណត់ចំនួនពិត $x$, $y$ ដើម្បីបាន $2\bar{z}_1 - (z_2 + y - 1) = 0$ ។

ដំណោះស្រាយ

ក. សរសេរ $z_1$ ជាទម្រង់ត្រីកោណមាត្រ រួចជាទម្រង់ពីជគណិត៖

យើងមាន $z_1 = \frac{2\left(\cos\frac{\pi}{12} + i\sin\frac{\pi}{12}\right)^2}{1+i\sqrt{3}}$

$z_1 = \frac{2\left(\cos\frac{2\pi}{12} + i\sin\frac{2\pi}{12}\right)}{2\left(\frac{1}{2} + i\frac{\sqrt{3}}{2}\right)} = \frac{\cos\frac{\pi}{6} + i\sin\frac{\pi}{6}}{\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}}$

$z_1 = \cos\left(\frac{\pi}{6} - \frac{\pi}{3}\right) + i\sin\left(\frac{\pi}{6} - \frac{\pi}{3}\right) = \cos\left(-\frac{\pi}{6}\right) + i\sin\left(-\frac{\pi}{6}\right)$

ដូចនេះ ទម្រង់ត្រីកោណមាត្រគឺ $z_1 = \cos\left(-\frac{\pi}{6}\right) + i\sin\left(-\frac{\pi}{6}\right)$

ទម្រង់ពីជគណិត៖ $z_1 = \frac{\sqrt{3}}{2} - \frac{1}{2}i$

ដូចនេះ ទម្រង់ពីជគណិតគឺ $z_1 = \frac{\sqrt{3}}{2} - \frac{1}{2}i$

ខ. កំណត់ចំនួនពិត $x$, $y$៖

យើងមាន $2\bar{z}_1 - (z_2 + y - 1) = 0$

ដោយ $z_1 = \frac{\sqrt{3}}{2} - \frac{1}{2}i \Rightarrow \bar{z}_1 = \frac{\sqrt{3}}{2} + \frac{1}{2}i$

$2\left(\frac{\sqrt{3}}{2} + \frac{1}{2}i\right) - \left[(1-i)x + (1-y)(1+i) + y - 1\right] = 0$

$\sqrt{3} + i - (x - xi + 1 + i - y - yi + y - 1) = 0$

$\sqrt{3} + i - x + xi - i + yi = 0$

$(\sqrt{3} - x) + (x + y)i = 0$

នាំឱ្យ $\sqrt{3} - x = 0 \Rightarrow x = \sqrt{3}$ និង $x + y = 0 \Rightarrow y = -\sqrt{3}$

ដូចនេះ $x = \sqrt{3}$ និង $y = -\sqrt{3}$

លំហាត់ II (១៥ ពិន្ទុ)

គណនាលីមីតខាងក្រោម៖

ក. $\lim_{x\to-1} \frac{1+x}{\sqrt{x^2+3}-2}$

ខ. $\lim_{x\to+\infty} \frac{x^2-x+2}{(e^x+2)(e^x-1)}$

គ. $\lim_{x\to+\infty} \left(\frac{x-1}{x+3}\right)^{x+2}$

ដំណោះស្រាយ

គណនាលីមីតខាងក្រោម៖

ក. $\lim_{x\to-1} \frac{1+x}{\sqrt{x^2+3}-2}$ (រាង $\frac{0}{0}$)

$= \lim_{x\to-1} \frac{(1+x)(\sqrt{x^2+3}+2)}{(x^2+3)-4} = \lim_{x\to-1} \frac{(1+x)(\sqrt{x^2+3}+2)}{x^2-1}$

$= \lim_{x\to-1} \frac{(1+x)(\sqrt{x^2+3}+2)}{(x-1)(x+1)} = \lim_{x\to-1} \frac{\sqrt{x^2+3}+2}{x-1}$

$= \frac{\sqrt{1+3}+2}{-1-1} = \frac{4}{-2} = -2$

ដូចនេះ $\lim_{x\to-1} \frac{1+x}{\sqrt{x^2+3}-2} = -2$

ខ. $\lim_{x\to+\infty} \frac{x^2-x+2}{(e^x+2)(e^x-1)}$

$= \lim_{x\to+\infty} \frac{x^2(1 - \frac{1}{x} + \frac{2}{x^2})}{e^{2x}(1 + \frac{2}{e^x})(1 - \frac{1}{e^x})}$

$= \lim_{x\to+\infty} \frac{x^2}{e^{2x}} \cdot \frac{1 - \frac{1}{x} + \frac{2}{x^2}}{(1 + \frac{2}{e^x})(1 - \frac{1}{e^x})} = 0 \cdot \frac{1}{1} = 0$

ដូចនេះ $\lim_{x\to+\infty} \frac{x^2-x+2}{(e^x+2)(e^x-1)} = 0$

គ. $\lim_{x\to+\infty} \left(\frac{x-1}{x+3}\right)^{x+2}$

$= \lim_{x\to+\infty} \left(\frac{x+3-4}{x+3}\right)^{x+2} = \lim_{x\to+\infty} \left(1 + \frac{-4}{x+3}\right)^{x+2}$

$= \lim_{x\to+\infty} \left[ \left(1 + \frac{-4}{x+3}\right)^{\frac{x+3}{-4}} \right]^{\frac{-4(x+2)}{x+3}} = e^{\lim_{x\to+\infty} \frac{-4x-8}{x+3}} = e^{-4} = \frac{1}{e^4}$

ដូចនេះ $\lim_{x\to+\infty} \left(\frac{x-1}{x+3}\right)^{x+2} = \frac{1}{e^4}$

លំហាត់ III (១៥ ពិន្ទុ)

ក. ដោះស្រាយសមីការ $(E): y'' + 5y' + 6y = 0$ ។

ខ. កំណត់ចម្លើយមួយនៃ $(E)$ បើគេដឹងថាបន្ទាត់ $(D): y = x - 1$ ប៉ះក្រាបនៃចម្លើយត្រង់ $x = 0$ ។

ដំណោះស្រាយ

ក. ដោះស្រាយសមីការ $(E): y'' + 5y' + 6y = 0$៖

សមីការសម្គាល់៖ $r^2 + 5r + 6 = 0$

$\Delta = 25 - 24 = 1 \Rightarrow r_1 = \frac{-5+1}{2} = -2, r_2 = \frac{-5-1}{2} = -3$

ដូចនេះ ចម្លើយទូទៅគឺ $y = Ae^{-2x} + Be^{-3x}$ ដែល $A, B \in \mathbb{R}$

ខ. កំណត់ចម្លើយមួយនៃ $(E)$៖

បន្ទាត់ប៉ះ $(D): y = x - 1$ ត្រង់ $x = 0$ នាំឱ្យ $y(0) = -1$ និង $y'(0) = 1$ (មេគុណប្រាប់ទិស)

$y(0) = A + B = -1$ (1)

$y'(x) = -2Ae^{-2x} - 3Be^{-3x} \Rightarrow y'(0) = -2A - 3B = 1$ (2)

តាម (1) $A = -1 - B$, ជួសក្នុង (2): $-2(-1 - B) - 3B = 1 \Rightarrow 2 + 2B - 3B = 1 \Rightarrow -B = -1 \Rightarrow B = 1$

នាំឱ្យ $A = -1 - 1 = -2$

ដូចនេះ ចម្លើយគឺ $y = -2e^{-2x} + e^{-3x}$

លំហាត់ IV (១៥ ពិន្ទុ)

ប្រធានវិញ្ញាសាគណិតវិទ្យានៃការប្រឡងមួយមានលំហាត់ពីជគណិត 6 និងធរណីមាត្រ 4 ។ បេក្ខជនម្នាក់ត្រូវធ្វើពីរលំហាត់ក្នុងចំណោមលំហាត់ទាំងអស់ទៅតាមជម្រើសរបស់ខ្លួន។

១. រកចំនួនករណីអាច។

២. រកប្រូបាបនៃព្រឹត្តិការណ៍៖

ក. A: សិស្សជ្រើសរើសបានលំហាត់ពីជគណិតទាំងពីរ។

ខ. B: សិស្សជ្រើសរើសបានលំហាត់ធរណីមាត្រទាំងពីរ។

គ. C: សិស្សជ្រើសរើសបានលំហាត់ប្រភេទខុសគ្នា។

ដំណោះស្រាយ

១. រកចំនួនករណីអាច៖

សរុបលំហាត់មាន $6 + 4 = 10$ លំហាត់។ រើស 2 លំហាត់។

$n(S) = C(10, 2) = \frac{10!}{2!8!} = 45$

ដូចនេះ ចំនួនករណីអាចគឺ $n(S) = 45$

២. រកប្រូបាបនៃព្រឹត្តិការណ៍៖

ក. A: សិស្សជ្រើសរើសបានលំហាត់ពីជគណិតទាំងពីរ៖

$n(A) = C(6, 2) = \frac{6!}{2!4!} = 15$

$P(A) = \frac{n(A)}{n(S)} = \frac{15}{45} = \frac{1}{3}$

ដូចនេះ $P(A) = \frac{1}{3}$

ខ. B: សិស្សជ្រើសរើសបានលំហាត់ធរណីមាត្រទាំងពីរ៖

$n(B) = C(4, 2) = \frac{4!}{2!2!} = 6$

$P(B) = \frac{n(B)}{n(S)} = \frac{6}{45} = \frac{2}{15}$

ដូចនេះ $P(B) = \frac{2}{15}$

គ. C: សិស្សជ្រើសរើសបានលំហាត់ប្រភេទខុសគ្នា៖

រើសបានពីជគណិត 1 និងធរណីមាត្រ 1៖

$n(C) = C(6, 1) \times C(4, 1) = 6 \times 4 = 24$

$P(C) = \frac{n(C)}{n(S)} = \frac{24}{45} = \frac{8}{15}$

ដូចនេះ $P(C) = \frac{8}{15}$

លំហាត់ V (១៥ ពិន្ទុ)

រកសមីការស្តង់ដាអេលីបដែលមានកំណុំ $F_1(0,1)$ ; $F_2(4,1)$ និងប្រវែងអ័ក្សធំស្មើ 10 ឯកតា។ សង់អេលីបនេះ។

ដំណោះស្រាយ

រកសមីការស្តង់ដាអេលីប៖

ដោយកំណុំទាំងពីរមានអរដោនេដូចគ្នា $y = 1$ នាំឱ្យអ័ក្សធំស្របនឹងអ័ក្សអាប់ស៊ីស។

ផ្ចិត $I(h, k)$ ជាចំណុចកណ្តាលនៃ $F_1F_2 \Rightarrow h = \frac{0+4}{2} = 2, k = \frac{1+1}{2} = 1 \Rightarrow I(2, 1)$

ចម្ងាយរវាងកំណុំ $2c = \sqrt{(4-0)^2 + 0^2} = 4 \Rightarrow c = 2$

ប្រវែងអ័ក្សធំ $2a = 10 \Rightarrow a = 5$

យើងមាន $b^2 = a^2 - c^2 = 25 - 4 = 21 \Rightarrow b = \sqrt{21} \approx 4.58$

សមីការស្តង់ដា៖ $\frac{(x-h)^2}{a^2} + \frac{(y-k)^2}{b^2} = 1$

ដូចនេះ សមីការគឺ $\frac{(x-2)^2}{25} + \frac{(y-1)^2}{21} = 1$

លំហាត់ VI (២៥ ពិន្ទុ)

ក្នុងតម្រុយមានទិសដៅវិជ្ជមាន $(O, \vec{i}, \vec{j}, \vec{k})$ គេឱ្យចំណុច $A(0, 2, 2)$ និងបន្ទាត់ $(D)$ ដែលមានសមីការ $\begin{cases} x = 1+t \\ y = 1-t \\ z = 2-t \end{cases}$ ដែល $t \in \mathbb{R}$ ។

ក. បង្ហាញថាប្លង់ $(P): x-y-z+4=0$ កាត់តាម $A$ ហើយកែងនឹងបន្ទាត់ $(D)$ ។

ខ. ប្លង់ $(P)$ កាត់អ័ក្ស $(ox), (oy)$ និង $(oz)$ រៀងគ្នាត្រង់ $M, N$ និង $P$ ។ រកកូអរដោនេនៃចំណុច $M, N$ និង $P$ ។

គ. បង្ហាញថា $MNP$ ជាត្រីកោណសម័ង្ស។

ឃ. គណនា $\vec{MP} \times \vec{MN}$ រួចទាញរកក្រឡាផ្ទៃនៃត្រីកោណ $MNP$ ។

ដំណោះស្រាយ

ក. បង្ហាញថាប្លង់ $(P)$ កាត់តាម $A$ ហើយកែងនឹងបន្ទាត់ $(D)$៖

យកកូអរដោនេ $A(0, 2, 2)$ ជួសក្នុង $(P): 0 - 2 - 2 + 4 = 0$ ពិត នាំឱ្យ $(P)$ កាត់តាម $A$ ។

វ៉ិចទ័រណរម៉ាល់នៃ $(P)$ គឺ $\vec{n} = (1, -1, -1)$ ។ វ៉ិចទ័រប្រាប់ទិសនៃ $(D)$ គឺ $\vec{u} = (1, -1, -1)$ ។

ដោយ $\vec{n} = \vec{u}$ នាំឱ្យប្លង់ $(P)$ កែងនឹងបន្ទាត់ $(D)$ ។

ខ. រកកូអរដោនេនៃចំណុច $M, N$ និង $P$៖

ចំណុចប្រសព្វនឹង $(ox): y=0, z=0 \Rightarrow x + 4 = 0 \Rightarrow x = -4 \Rightarrow M(-4, 0, 0)$

ចំណុចប្រសព្វនឹង $(oy): x=0, z=0 \Rightarrow -y + 4 = 0 \Rightarrow y = 4 \Rightarrow N(0, 4, 0)$

ចំណុចប្រសព្វនឹង $(oz): x=0, y=0 \Rightarrow -z + 4 = 0 \Rightarrow z = 4 \Rightarrow P(0, 0, 4)$

ដូចនេះ $M(-4, 0, 0), N(0, 4, 0), P(0, 0, 4)$

គ. បង្ហាញថា $MNP$ ជាត្រីកោណសម័ង្ស៖

$MN = \sqrt{(0+4)^2 + 4^2 + 0^2} = \sqrt{16+16} = \sqrt{32} = 4\sqrt{2}$

$MP = \sqrt{(0+4)^2 + 0^2 + 4^2} = \sqrt{16+16} = 4\sqrt{2}$

$NP = \sqrt{0^2 + (0-4)^2 + 4^2} = \sqrt{16+16} = 4\sqrt{2}$

ដោយ $MN = MP = NP = 4\sqrt{2}$ នាំឱ្យ $MNP$ ជាត្រីកោណសម័ង្ស។

ឃ. គណនា $\vec{MP} \times \vec{MN}$ រួចទាញរកក្រឡាផ្ទៃ៖

$\vec{MP} = (4, 0, 4)$ និង $\vec{MN} = (4, 4, 0)$

$\vec{MP} \times \vec{MN} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 4 & 0 & 4 \\ 4 & 4 & 0 \end{vmatrix} = (0 - 16)\vec{i} - (0 - 16)\vec{j} + (16 - 0)\vec{k} = -16\vec{i} + 16\vec{j} + 16\vec{k}$

$S_{MNP} = \frac{1}{2}|\vec{MP} \times \vec{MN}| = \frac{1}{2}\sqrt{(-16)^2 + 16^2 + 16^2} = \frac{1}{2}\sqrt{3 \times 16^2} = 8\sqrt{3}$

ដូចនេះ ក្រឡាផ្ទៃគឺ $S_{MNP} = 8\sqrt{3}$ ឯកតាផ្ទៃ

លំហាត់ VII (២៥ ពិន្ទុ)

$f$ ជាអនុគមន៍កំណត់ចំពោះ $x > 0$ ដោយ $f(x) = 2\left(1 - \frac{\ln x}{x}\right)$ ហើយមានក្រាប $(C)$ ។

ក. គណនា $\lim_{x\to 0^+} f(x)$ និង $\lim_{x\to +\infty} f(x)$ ។ ទាញរកអាស៊ីមតូតនៃ $(C)$ ។

ខ. គណនា $f'(x)$ និងសិក្សាសញ្ញារបស់វា។ កំណត់តម្លៃបរមារបៀបនៃ $f$ ។ សង់តារាងអថេរភាពនៃ $f$ ។

គ. កំណត់កូអរដោនេនៃចំណុចប្រសព្វ $M$ រវាងក្រាប $(C)$ និងអាស៊ីមតូតដេករបស់វា។ កំណត់សមីការបន្ទាត់ $(L)$ ប៉ះនឹងក្រាប $(C)$ ត្រង់ $M$ ។

ឃ. សង់ $(C)$ និង $(L)$ ក្នុងតម្រុយតែមួយ។ (យក $e = 2.7 ; \frac{2}{e} = 0.7$)

ង. គណនាក្រឡាផ្ទៃប្លង់ខណ្ឌដោយក្រាប $(C)$ និងអ័ក្ស $(ox)$ លើចន្លោះ $[1, e]$ ។

ដំណោះស្រាយ

ក. គណនាលីមីត និងទាញរកអាស៊ីមតូត៖

$\lim_{x\to 0^+} f(x) = \lim_{x\to 0^+} 2\left(1 - \frac{\ln x}{x}\right) = 2(1 - (-\infty)) = +\infty$ នាំឱ្យ $x=0$ ជាអាស៊ីមតូតឈរ។

$\lim_{x\to +\infty} f(x) = \lim_{x\to +\infty} 2\left(1 - \frac{\ln x}{x}\right) = 2(1 - 0) = 2$ នាំឱ្យ $y=2$ ជាអាស៊ីមតូតដេក។

ខ. គណនា $f'(x)$ និងសិក្សាសញ្ញា៖

$f'(x) = -2\left(\frac{1 - \ln x}{x^2}\right) = \frac{2(\ln x - 1)}{x^2}$

$f'(x) = 0 \Rightarrow \ ln x = 1 \Rightarrow x = e$

បើ $x \in (0, e)$ នោះ $f'(x) < 0$ ($f$ ចុះ)។ បើ $x > e$ នោះ $f'(x) > 0$ ($f$ កើន)។

$f$ មានអប្បបរមាត្រង់ $x=e$ គឺ $f(e) = 2\left(1 - \frac{1}{e}\right) = 2 - \frac{2}{e} \approx 2 - 0.7 = 1.3$

គ. ចំណុចប្រសព្វ $M$ និងបន្ទាត់ប៉ះ $(L)$៖

$2\left(1 - \frac{\ln x}{x}\right) = 2 \Rightarrow \frac{\ln x}{x} = 0 \Rightarrow x = 1$។ ដូចនេះ $M(1, 2)$ ។

សមីការបន្ទាត់ប៉ះត្រង់ $M(1, 2)$៖ $y = f'(1)(x - 1) + 2$

$f'(1) = \frac{2(-1)}{1} = -2 \Rightarrow y = -2(x - 1) + 2 = -2x + 4$

ដូចនេះ $(L): y = -2x + 4$

ង. គណនាក្រឡាផ្ទៃប្លង់៖

$S = \int_1^e f(x) dx = \int_1^e 2\left(1 - \frac{\ln x}{x}\right) dx$

$S = \left[ 2x - (\ln x)^2 \right]_1^e = (2e - 1) - (2 - 0) = 2e - 3$

ដូចនេះ $S = 2e - 3 \approx 2(2.7) - 3 = 2.4$ ឯកតាផ្ទៃ
