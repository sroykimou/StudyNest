លំហាត់អនុវត្តន៍ ADN

កម្រងលំហាត់ជីវវិទ្យាថ្នាក់ទី១២ (ថ្នាក់វិទ្យាសាស្ត្រ)
ផ្នែកទី ១៖ គណនាចំនួននុយគ្លេអូទីត (M)
លំហាត់គំរូទី ១

ADN មួយមានផលបូកនុយគ្លេអូទីតសរុបស្មើ 40000 និងនុយគ្លេអូទីតប្រភេទ G = 2000។ ចូររកចំនួននុយគ្លេអូទីតនីមួយៗរបស់ ADN?

ចម្លើយ
១. រកនុយគ្លេអូទីតនីមួយៗរបស់ADN
បម្រាប់៖ M = 40000 នុយគ្លេអូទីត, G = 2000 នុយគ្លេអូទីត តាមគោលការណ៍បំពេញបាស A-T ⇒ A=T, C-G ⇒ C=G ⇒ M = A + T + C + G      = 2A + 2C ⇒ A = M/2 - C      = 40000/2 - 2000      = 18000 នុយគ្លេអូទីត ដូចនេះ A = T = 18000 នុយគ្លេអូទីត            C = G = 2000 នុយគ្លេអូទីត

២

៣

៤
ម៉ូលេគុល ADN មួយមាននុយប្រភេទ C ច្រើនជាង T ចំនួន 400 ហើយគេដឹងថានុយគ្លេអូទីតសរុបមានចំនួន 5000។ គណនាចំនួននុយគ្លេអូទីតនីមួយៗរបស់ ADN នេះ។

ផ្នែកទី ២៖ គណនាប្រវែងម៉ូលេគុល (ℓ)
លំហាត់គំរូទី ២

ADN មួយមានផលបូកនុយគ្លេអូទីតសរុបចំនួន 7000។ គណនាប្រវែងម៉ូលេគុល ADN?

ចម្លើយ
១. គណនាប្រវែងម៉ូលេគុល ADN
បម្រាប់៖ M = 7000 នុយគ្លេអូទីត ដោយ១នុយគ្លេអូទីតទៅ១នុយគ្លេអូទីតទៀតមានប្រវែង 0.34nm ហើយ ADN ជាច្រវាក់ទ្វេ ⇒ ℓ = (M / 2) × 0.34     = (7000 / 2) × 0.34     = 1190 nm ដូចនេះ ℓ = 1190 nm
លំហាត់អនុវត្តន៍ទី ២
២

៤

៥

ផ្នែកទី ៣៖ គណនាចំនួនរលក ឬសៀពៀរ (C)
លំហាត់គំរូទី ៣

ម៉ូលេគុល ADN មួយមានប្រវែង 1700nm។ គណនាចំនួនរលក?

ចម្លើយ
១. គណនាចំនួនរលក
បម្រាប់៖ ℓ = 1700nm ដោយ១ជំហានស្មើនឹង 3.4nm ⇒ ចំនួនជំហាន = ℓ / 3.4               = 1700 / 3.4               = 500 ជំហាន ដូចនេះ ចំនួនជំហាន = 500 ជំហាន
