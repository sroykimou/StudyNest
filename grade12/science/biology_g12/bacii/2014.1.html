២. គេប្រើសូលុយស្យុង 10% នៃសូដ្យូមអ៊ីដ្រុកស៊ីត (NaOH) និង 0.5% ទង់ដែងស៊ុលផាត (CuSO4) ដើម្បី៖

២. បានជានុយក្លេអូទីតមានតែ៤ប្រភេទអាចបង្កើតម៉ូលេគុល ADN ខុសគ្នាជាច្រើនប្រភេទ ព្រោះ

ចម្លើយ សំណួរទី IV

ពេលឮទូរសព្ទរោទ៍ អ្នកលើកទូរសព្ទឡើងដើម្បីឆ្លើយតប​ ។ក្នុងករណីនេះមានណឺរ៉ូន ៣ ប្រភេទចូលរួមគឺ៖ ណឺរ៉ូនវិញ្ញាណនាំ, ណឺរ៉ូនភ្ជាប់ឬអន្តរណឺរ៉ូន, និងណឺរ៉ូនចលករ។

រៀបរាប់ពីនាទីរបស់ណឺរ៉ូននីមួយៗ៖

- ណឺរ៉ូនវិញ្ញាណ៖ ដឹកនាំព័ត៌មាន ឬ​អាំងភ្លុចប្រសាទពីធ្មួលវិញ្ញាណនៅក្នុងត្រចៀកទៅកាន់មជ្ឈមណ្ឌលប្រសាទ(ខួរក្បាល)។
- ណឺរ៉ូនភ្ជាប់ឬណឺរ៉ូនអន្តរ មាននាទីបញ្ជូនបន្តព័ត៌មានពីណឺរ៉ូនវិញ្ញាណនាំទៅណឺរ៉ូនចលករ ក្រោយការបកស្រាយអាំងភ្លុចប្រសាទពីខួរក្បាល។
- ណឺរ៉ូនចលករ មាននាទីបញ្ជូនអាំងភ្លុចប្រសាទ ពីមជ្ឈមណ្ឌលប្រសាទទៅកាន់សរីរាង្គប្រតិកម្ម (សាច់ដុំ) ។

ចម្លើយ សំណួរទី V

១. រកចំនួននុយក្លេអូទីតសរុបរបស់ម៉ូលេគុល ADN

តាមបម្រាប់ \(T = 640000\) នុយក្លេអូទីត
\(C = 50\%\) នៃចំនួននុយក្លេអូទីត \(T\)
នាំឲ្យ \(C = \frac{50 \times T}{100} = \frac{50 \times 640000}{100} = 320000\) នុយក្លេអូទីត
តាមគោលការណ៍បំពេញបាសអាសូត A-T , C-G នាំឱ្យ A = T , C = G
តាមរូបមន្ត M = A + T + C + G នាំឲ្យ M = 2(T + C)
គេបាន M = 2(640000) + 2(320000) = 1920000 នុយក្លេអូទីត
ដូចនេះ ចំនួននុយក្លេអូទីតសរុបរបស់ម៉ូលេគុល ADN គឺ M = 1920000 នុយក្លេអូទីត

២. រកចំនួននុយក្លេអូទីតសេរីរបស់ម៉ូលេគុល ADN នេះក្រោយពេលស្វ័យដំឡើងទ្វេ ៣លើក

ដោយម៉ូលេគុល ADN មេមួយ ស្វ័យដំឡើងទ្វេ៖
1 ដង បាន ADN កូន \(2^1\)
2ដង បាន ADN កូន \(2^2\)
3 ដង បាន ADN កូន \(2^3\)
......................
\(n\)ដង បាន ADN កូន \(2^n\)

បើ ADNមេមួយស្វ័យដំឡើង៣ដង បង្កើតបាន ADN កូនសរុប \(2^3\) ដែលក្នុងនោះមាន ADN ១ជា ADN មេនោះចំនួន ADN កូនដែលកើតថ្មីស្មើនឹង \((2^3 - 1)\)
គេបាន\( M' = M(2^3 - 1) \)
\(M' = 1920000(2^3 - 1) = 1920000 \times 7 = 13440000\) នុយក្លេអូទីតសេរី
ដូចនេះ ចំនួននុយក្លេអូទីតសេរីរបស់ម៉ូលេគុល ADN ក្រោយស្វ័យដំឡើងទ្វេ៣ដងគឺ \(M' = 13440000\) នុយក្លេអូទីតសេរី

៣. រកចំនួនសម្ព័ន្ធគីមីក្នុងម៉ូលេគុល ADN

ដោយនុយក្លេអូទីត២ភ្ជាប់គ្នាដោយសម្ព័ន្ធគីមី១(ឬសម្ព័ន្ធកូវ៉ាឡង់១)ក្នុងច្រវ៉ាក់ម្ខាងៗរបស់ម៉ូលេគុល ADN
តាមរូបមន្ត ចំនួនសម្ព័ន្ធគីមីក្នុងម៉ូលេគុល ADN = M - 2
គេបាន ចំនួនសម្ព័ន្ធគីមីក្នុងម៉ូលេគុល ADN​ = 1920000 - 2 = 1919998 សម្ព័ន្ធគីមី
ដូចនេះ ចំនួនសម្ព័ន្ធគីមីក្នុងម៉ូលេគុល ADN = 1919998 សម្ព័ន្ធគីមី ។
ចម្លើយ សំណួរទី VI

១. គណនាប្រវែងម៉ូលេគុល ARNm

តាមបម្រាប់៖ ម៉ូលេគុលប្រូតេអ៊ីន ១ មាន 178 អាស៊ីតអាមីណេ

ដោយរីបូនុយក្លេអូទីត៣ជាក្រមនៃអាស៊ីតអាមីណេមួយនៅលើម៉ូលេគុល ARNm មានកូដុងផ្តើមមួយហើយកូដុងស្តុបមួយ
នាំឲ្យ ចំនួនអាស៊ីតអាមីណេ = m/3 + 2
m = ចំនួនអាស៊ីតអាមីណេ × 3 + 6
គេបាន \(m = (178 \times 3) + 6 = 540\) រីបូនុយក្លេអូទីត

ដោយរីបូនុយក្លេអូទីតមួយទៅរីបូនុយក្លេអូទីតមួយមានប្រវែង 0.34nm
នាំឲ្យ \(l_{ARN_m} = m \times 0.34\text{nm}\)
គេបាន \( = 540 \times 0.34\text{nm} = 183.6\text{nm}\)

ដូចនេះ \(\boxed{l_{ARN_m} = 183.6 \text{nm}}\)

២. រកចំនួននៃប្រភេទនុយក្លេអូទីតរបស់សែន និងចំនួននៃប្រភេទនុយក្លេអូទីតរបស់ច្រវ៉ាក់ទោលនីមួយៗនៃសែន

តាមបម្រាប់៖ \(A - G = 200 \quad (1)\) ; \(U = 250\) ; \(C_{ARN_m} = 60\)


ដោយម៉ូលេគុល ARNm ចម្លងចេញពីច្រវ៉ាក់នៃសែន
នាំឲ្យ \(m = \frac{M}{2} = 540\) នុយក្លេអូទីត

តាមគោលការណ៍បំពេញបាសអាសូត A–T ; C–G នាំឲ្យ A = T ; C = G

ដោយ \(M = A + T + C + G\)
\(M = 2A + 2G = 2(A + G)\)
\(\Rightarrow A + G = \frac{M}{2} \)
\(\Rightarrow A + G = 540 \quad (2)\)
ពី \((1)\) និង \((2)\) ជាប្រព័ន្ធសមីការ

\(\begin{cases} A - G = 200 \\ A + G = 540 \end{cases}\)

\(2A = 740 \Rightarrow A = \frac{740}{2} = 370\)

យក A​=370 ជួសក្នុង \((2)\)
\( \Rightarrow 370 + G = 540\)
\(\Rightarrow G = 540 - 370 = 170\) នុយក្លេអូទីត

ដូចនេះចំនួននៃប្រភេទនុយក្លេអូទីតរបស់សែន A = T = 370 នុយក្លេអូទីត
និង​ C = G = 170 នុយក្លេអូទីត
សន្មត ARNm ចម្លងចេញពីត្រាក់ស្គ្រីបទី ១ របស់សែន
តាមគោលការណ៍បំពេញបាសបំពេញ

\(A_1 = U = 250\) ; \(G_1 = C_{ARN_m} = 60\)

\(A\)សែន \(= A_1 + A_2\)
ដែល \(A_2 = T_1\)
\(\Rightarrow A\)សែន \(= A_1 + T_1\)
\(\Rightarrow T_1 = A\)សែន \( - A_1\)
\(= 370 - 250\)
\(= 120\) នុយក្លេអូទីត

ដោយ \(C\)សែន \(= C_1 + C_2\) ដែល \(C_2 = G_1\)
\(= C_1 + G_1\)
\(\Rightarrow C_1 = C\)សែន \( - G_1\)
\(= 170 - 60\)
\(= 110\) នុយក្លេអូទីត

ដូច្នេះ៖
\(A_1 = T_2 = 250\) នុយក្លេអូទីត
\(T_1 = A_2 = 120\) នុយក្លេអូទីត
\(C_1 = G_2 = 110\) នុយក្លេអូទីត
\(G_1 = C_2 = 60\) នុយក្លេអូទីត

៣. រកសមាមាត្រភាគរយនៃប្រភេទនុយក្លេអូទីតនីមួយៗរបស់ម៉ូលេគុល ARNm
